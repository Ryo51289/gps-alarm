# Bảng task — MVP 1

Chuỗi mặc định cho mỗi task: `solution-designer → coder → reviewer → tester`.
Task loại **spike** dùng chuỗi rút gọn: `solution-designer` (kế hoạch thí nghiệm) → `coder` (app thí nghiệm)
→ người chạy trên máy thật → `solution-designer` (kết luận Go/No-go trong `docs/spikes/<ID>.md`).

Môi trường: `[linux]` container/máy Linux · `[mac]` cần macOS + Xcode · `[device]` cần máy thật + người. · `[wsl]` WSL Swift 6.4.1 + xtool SDK trên máy dev · `[ci-mac]` GitHub Actions macOS · `[paid]` cần tài khoản Apple Developer trả phí.

**Ưu tiên từ 05/11/2026 (PO): hoàn thiện iOS trước, Android sau** — lộ trình `docs/PLAN-ios.md`.
