  manifest.
- **"295 run khớp manifest ở HEAD"**: **không nên** nếu làm bằng `git show HEAD:fixtures/p05/manifest.json`. Có 3 lý do:
  1. Sau commit T11.3, `HEAD` chứa sẵn 303 run. Khi đó phép so trở thành "kết quả tính = manifest commit", trùng `P05ManifestTest`. Nếu còn giữ vế nào

     chủ ý (T12.4/T10.7 nếu P05 đổi), là đỏ, dù lỗi không nằm ở engine.
  3. `added.all { it.startsWith("$TRACE/") }` (dòng 247) và "đếm 295" sẽ đỏ ở **T11.4**: TR41/TR42/TR40b thêm run mới, trong khi test của T11.3
