### 4. Sửa module tìm kiếm T24 (`lib/features/destination/domain/station_search.dart`, `station_query.dart`)

#### 4.1 API (thay đổi tương thích ngược)

```dart
// station_search.dart
List<StationMatch> search(String query, {int limit = kDefaultSearchLimit, StationKind? kindHint});
// kindHint: dùng khi truy vấn KHÔNG có tiền tố loại (chip lọc của màn 2). Tiền tố trong truy vấn thắng.

// station_query.dart (thêm)
/// Folded qualifier phrases stripped from the front of a coach/bus core name
/// for the "bến xe <city>" rule (T23 §4.3). Longest first.
const List<List<String>> kQualifierPhrases = [
  ['lien', 'tinh'], ['trung', 'tam'], ['thanh', 'pho'],
  ['phia', 'bac'], ['phia', 'nam'], ['phia', 'dong'], ['phia', 'tay'],
  ['tp'], ['bac'], ['nam'], ['dong'], ['tay'],
];
/// Repeatedly removes a leading phrase of [kQualifierPhrases] while at least one token remains.
/// Returns null when nothing was removed.
List<String>? stripLeadingQualifiers(List<String> coreTokens);

/// Province tokens without a leading "tp" / "thanh pho" / "tinh" (keeps ≥ 1 token).
List<String> provinceCoreTokens(String province);
```

`_Key` thêm `compact` (= `tokens.join('')`) và `qualified` (= `stripLeadingQualifiers(tokens)`, tính sẵn khi dựng index). `_Entry` thêm
bốn chuỗi tính sẵn cho khớp theo tỉnh: `P.join(' ')`, `P.join('')`, `Pc.join(' ')`, `Pc.join('')` với `P = foldTokens(province)` (đã có) và
`Pc = provinceCoreTokens(province)`.

#### 4.2 Thuật toán (thay §7.3 của T24 ở các điểm ghi "MỚI")

```
search(query, limit, kindHint: hintParam):
  q = parseStationQuery(query); if q.tokens.isEmpty || limit <= 0 → []
  hint = q.kindHint ?? hintParam
  Q = q.tokens; qs = Q.join(' '); qc = Q.join('')
  for e in entries:
    hinted = hint != null && hint == e.station.kind
    best = null
    for k in e.keys (name trước, alias sau):
      m = matchKey(k, Q, qs, qc, e, hinted); if m == null continue
      score = m.base − (k.alias ? 25 : 0) + (hinted ? 150 : 0)
      giữ m nếu score > best.score (hoà → khoá đứng trước)
    // MỚI — khớp theo tỉnh (chỉ khi có gợi ý cùng loại), cấp station:
    // P = foldTokens(province), Pc = provinceCore; so khớp trọn chuỗi, không khớp tiền tố
    if hinted && (qs == Pc.join(' ') || qs == P.join(' ')
                  || (qc.length >= 4 && (qc == Pc.join('') || qc == P.join('')))):
      cand = (tier: provinceAssisted, base 800, viaAlias false, keyLen = độ dài khoá tên)
      score = 800 + 150; thay best nếu best == null || score > best.score
    group = hinted && best.tier ∉ {substring, fuzzy} ? 0 : 1          // MỚI
  sort theo: group ↑, score ↓, kind ↑ (train<coach<bus), keyLen ↑, nameAscii ↑, id ↑
  trả tối đa limit

matchKey(k, Q, qs, qc, e, hinted):        // thử theo thứ tự, lấy bậc đầu tiên đạt
  1 k.text == qs                                            → exact          1000
  2 qc.length >= 4 && k.compact == qc                       → exact           990   MỚI ("hanoi", "sapa")
  3 hinted && e.kind != train && k.qualified != null && qc.length >= 3
       && (k.qualified.join(' ') == qs || (qc.length >= 4 && k.qualified.join('') == qc))
                                                            → orderedTokens   950   MỚI ("Bến xe Bắc Vinh")
  4 k.text.startsWith(qs)                                   → prefix          900
  5 qc.length >= 4 && k.compact.startsWith(qc)              → prefix          890   MỚI ("hano", "nhatr")
  6 orderedTokens (như T24)                                 → orderedTokens   700
  7 anyOrderTokens (như T24)                                → anyOrderTokens  600
  8 provinceAssisted (như T24)                              → provinceAssisted 500
  9 qs.length >= 3 && k.text.contains(qs)                   → substring       300
 10 fuzzy (như T24), E = tổng lỗi, 1 <= E <= 3              → fuzzy   200 − 50·E   MỚI: E ≥ 4 → không khớp
```

- Không có gợi ý loại (`hint == null`): bước 3 và khớp theo tỉnh không chạy, mọi mục `group = 1` → thứ tự **y hệt T24** trừ hai luật bỏ khoảng
  trắng (bước 2, 5) và chặn E ≥ 4. Vì vậy TC22–TC33, test của tester T24 (`station_search_edge_test.dart`,
  `stations_asset_acceptance_test.dart`) giữ xanh; coder chạy lại toàn bộ và ghi vào Implementation notes.
- Bậc báo ra (`tier`) là loại khớp chuỗi; điểm có thể cao hơn bậc kế trên trong bảng T24 (950 dưới nhãn `orderedTokens`, 800 dưới nhãn
  `provinceAssisted`). Ghi rõ trong doc comment của `StationMatchTier`. Thứ tự sắp chỉ dựa vào `group` + `score`.
- Không khớp fuzzy theo dạng bỏ khoảng trắng (giữ test T24 `phuongtrnga` → rỗng).
- Mọi kết quả trả về có điểm > 0 (fuzzy tối thiểu 50 − 25 alias = 25).

**Vòng đời phiên** (trong controller):
```

onQuery(q) ở chế độ places:
   queryChars(q) < 3 → placesState = typeMore; huỷ debounce

        r = await client.autocomplete(q, token); nếu seq đổi → bỏ; else results(r) | empty
selectPrediction(p): placesState = resolving(p.placeId)
```

### 10. Máy trạng thái lựa chọn (`DestinationController`)

```dart
final class DestinationState {
  final String query; final DestinationFilter filter;
  final AsyncValue<StationCatalog> catalog;          // từ stationCatalogProvider
  final List<StationMatch> offline;                  // offlineResults(...)
  final Map<String, double> distanceByStationId;     // chỉ trong bộ nhớ của màn
  final PlacesUiState places;                        // sealed: notConfigured | typeMore | loading | results(list, resolvingId?) | empty | offline | unavailable
  final Selection? selection;                        // { TripDestination destination; DestinationSource source; MapPoint anchor; String anchorName }
  final int cameraRequestId;                         // tăng khi cần animate tới lựa chọn mới
  final PinUndo? undo;                               // lựa chọn trước lần dời gần nhất
}
```

| Sự kiện | Chuyển trạng thái |
|---|---|
| gõ chữ | `query` mới; filter ≠ places → `offline = offlineResults(...)` đồng bộ (search < 1 ms, TC34) + hẹn đo khoảng cách (150 ms); filter = places → §8. **Không** xoá `selection` |
| đổi chip | tính lại `offline`; vào places → `enterPlaces`; rời places → `leavePlaces` |
| chạm hàng ga/bến | `selection = (TripDestination.fromStation(s), station, anchor = (s.lat, s.lng), anchorName = s.name)`; `cameraRequestId++`; panel → 0.30 |
| chọn gợi ý Places | xem §8; thành công → selection `places`, `cameraRequestId++` |
| nhấn giữ bản đồ tại P | `selection = (TripDestination(name: destinationPinned, lat, lng, kind: pin), mapPin, anchor = P, anchorName = destinationPinned)`; `cameraRequestId` giữ nguyên; `undo` = selection cũ (có thể null) |
| kéo ghim xong tại P | `undo` = selection cũ; `afterPinMove(current, source, anchor, P, …)`; nếu đổi thành pin thì `anchor = P`, `anchorName = destinationPinned`. SnackBar `destinationPinMoved(formatDistanceShort(dời))` + action `commonUndo` → khôi phục `undo` |
| đo khoảng cách | lấy ≤ 20 station đang hiện chưa có trong `distanceByStationId`; gọi `distancesFromLastKnownM(pairs, kLastKnownMaxAgeMs)`; null → không hiện, không gọi lại trong 30 s; `BridgeException` → như null + non-fatal `pigeonCallFailed` |

**Vòng đời / lỗi**
- Màn hoàn toàn trong bộ nhớ (`autoDispose`); app bị kill hoặc khởi động lại máy → mở lại là trạng thái rỗng. Không chạm Location/Trip/Alarm,
  không ảnh hưởng chuyến đang chạy.
- Mất mạng: tìm offline + chọn ga vẫn chạy; bản đồ nền có thể trắng (PRD §5 cho phép); Places → `offline`.
- Mất quyền vị trí giữa chừng: lần đo kế tiếp trả null → ẩn khoảng cách. Không có Doze/background: màn chỉ chạy khi hiển thị.
- `stationCatalogProvider` = `FutureProvider<StationCatalog>` giữ suốt phiên (không autoDispose, 1–2 MB, T22 có thể dùng lại); lỗi không tự retry
  (T22 D3), nút "Thử lại" invalidate. `load()` chỉ gọi khi mở màn 2 (cold start không đổi).

### 11. Pin, quyền riêng tư, a11y

- **Pin:** không chạy nền; đo khoảng cách chỉ đọc vị trí cache (không bật GPS); Places chỉ khi người dùng chủ động, debounce.
- **Quyền riêng tư:**
  - Nội dung gõ chỉ tới Google ở chế độ Places, có dòng công bố. Vị trí người dùng không gửi đi đâu, không vào Dart (D9).
  - Không log query, tên ga/địa chỉ, toạ độ, URL, key ở **mọi mức** trong `lib/features/destination/**` (TC36 của T24 mở rộng: TS40).
  - `toString()` của `MapPoint`, `PlacePrediction`, `PlacesException`, `Selection`, `DestinationState` không chứa tên/toạ độ/query (TS41).
  - `destination_selected` chỉ có `source` + `kind` (T29 allowlist). Non-fatal chỉ kèm lớp lỗi + status.
  - Đích Places được lưu vào lịch sử/điểm đã lưu (T22) → Q1.
- **a11y:** vùng chạm ≥ 48 (nút nổi 48, nút lưu 56, chip 48, hàng ≥ 64); nút chỉ có icon đều có `semanticLabel`; hàng đang chọn có semantics
  `selected`; dòng ghi công OSM là `link`; trạng thái lỗi Places dùng `NapBanner(announce: true)`; bản đồ không phải đường duy nhất để chọn
  đích (mọi đích chọn được bằng tìm kiếm); `TextScaler` 2.0 không tràn (thanh dưới cho chữ nút xuống 2 dòng).
- **Copy:** xem §12.
