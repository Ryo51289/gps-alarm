### 2. Cài toolchain trên Windows

Đường dẫn chốt: Flutter SDK đặt ở **`D:\src\flutter`**, pub cache ở **`D:\src\pub-cache`**, tức là **cùng ổ với repo**
(`D:\work\gps-alarm`). Lý do: khi project và pub cache nằm khác ổ, Kotlin incremental compile của plugin Android có
thể lỗi `this and base files have different roots` (flutter/flutter#105395, vẫn đang mở) [R8]. T00 chưa có plugin
nên chưa gặp lỗi này, nhưng T15+ sẽ gặp. Đường dẫn không có dấu cách và không cần quyền admin, đúng yêu cầu của CLAUDE.md.
CLAUDE.md đang lấy ví dụ `C:\src\flutter`: đề nghị orchestrator cập nhật (xem "Thay đổi tài liệu liên quan").
Nếu máy đã có Flutter ở `C:\` và build chạy được thì giữ nguyên, chỉ cần đặt `PUB_CACHE` sang ổ D.

Công cụ dòng lệnh dùng trong Git Bash: `flutter` (script `bin/flutter` tự chuyển sang `flutter.bat` khi chạy trên
MINGW/MSYS [R6]), `./gradlew` (cần `JAVA_HOME`), `sdkmanager.bat`, `adb`.
**Không truyền chuỗi tiếng Việt qua tham số dòng lệnh** (`flutter.bat` và console codepage có thể làm hỏng dấu).
Mọi chuỗi có dấu phải ghi vào file UTF-8 bằng công cụ Edit/Write.

import 'package:flutter/services.dart' show appFlavor;

/// Build flavor. Unknown or missing values fall back to [dev] so that a
/// misconfigured build never talks to production services.
enum AppFlavor {
  dev,
  prod;

  static AppFlavor parse(String? raw) => raw == 'prod' ? prod : dev;

}

### 4. Flavor dev/prod (Android)

Cách làm: **một entrypoint `lib/main.dart` + Gradle `productFlavors` + `appFlavor`**. Không dùng `main_dev.dart`/
`main_prod.dart`, cũng không dùng `--dart-define` riêng. Đây là cách đơn giản nhất: không có `-t` trong lệnh, và
Flutter tự truyền tên flavor sang Dart. Thêm `default-flavor: dev` vào pubspec để `flutter run` và
`flutter build apk --debug` không cần `--flavor` vẫn ra bản dev. Nhờ vậy tiêu chí của TASKS.md và lệnh trong
CLAUDE.md giữ nguyên [R14].

`app/android/app/build.gradle.kts`, các thay đổi so với template:
```kotlin
android {
    // namespace, compileSdk, ndkVersion, compileOptions: giữ nguyên template
    defaultConfig {
        applicationId = "app.napstop"          // template đã sinh sẵn giá trị này
        minSdk = 26                              // PRD §5: Android 8.0+. Thay cho flutter.minSdkVersion (=24)
        targetSdk = flutter.targetSdkVersion     // = 36 với Flutter 3.47, đạt yêu cầu Play [R4]
        // versionCode, versionName: giữ nguyên
    }

    flavorDimensions += "default"
    productFlavors {
        create("dev") {
            dimension = "default"
            applicationIdSuffix = ".dev"         // app.napstop.dev, cài song song được với prod
            versionNameSuffix = "-dev"
        }
        create("prod") {
            dimension = "default"
        }
    }
    // buildTypes: giữ nguyên template
}

kotlin { /* giữ nguyên */ }

dependencies {
    testImplementation("junit:junit:4.13.2")
}

flutter { source = "../.." }
```
Tên app theo flavor dùng **resource XML**, không dùng `resValue` trong Kotlin DSL, để tránh rủi ro encoding khi
đặt chuỗi tiếng Việt trong script Gradle trên Windows. Flavor source set ghi đè `main` [R15]:
- `android/app/src/main/res/values/strings.xml`: `<string name="app_name">NapStop</string>`
- `android/app/src/dev/res/values/strings.xml`: `<string name="app_name">NapStop Dev</string>`
- `android/app/src/main/AndroidManifest.xml`: `android:label="@string/app_name"` (thay giá trị `"app"` của template).
  Ngoài dòng này, **không** thêm `<uses-permission>`, `<service>` hay `<receiver>` nào.
- Mọi file XML: UTF-8 không BOM, có `<?xml version="1.0" encoding="utf-8"?>`.

Lệnh theo flavor (chạy trong `app/`):

| Mục đích | Lệnh | Output |
|---|---|---|
| Chạy dev | `flutter run` (hoặc `flutter run --flavor dev`) | |
| Chạy prod | `flutter run --flavor prod` | |
| APK debug dev | `flutter build apk --debug` (hoặc `--flavor dev`) | `build/app/outputs/flutter-apk/app-dev-debug.apk` |
| APK debug prod | `flutter build apk --debug --flavor prod` | `build/app/outputs/flutter-apk/app-prod-debug.apk` |

**Lưu ý về Gradle wrapper:** template Flutter **không commit** `gradlew`, `gradlew.bat` và `gradle-wrapper.jar`
(`android/.gitignore`). Flutter tool tự chép các file này vào khi build (`injectGradleWrapperIfNeeded` [R16]). Sau khi
clone mới, phải chạy `flutter build apk --config-only` (hoặc một lệnh build bất kỳ) trước `./gradlew`. Lệnh này cũng
ghi `android/local.properties` (`flutter.sdk`, `sdk.dir`) [R17].
