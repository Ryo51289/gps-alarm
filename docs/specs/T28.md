### 3. Lịch sử

#### 3.1 Repository (bổ sung `lib/core/trip/data/trips_repository.dart`, chỉ thêm, không đổi chữ ký cũ)

```dart
/// Rows read by screen 11, newest first.
const int kHistoryLimit = 200;

/// A trip row whose start is older than this and that has no native trip is an orphan (D4).
const Duration kOrphanGrace = Duration(seconds: 120);

enum ApplyFinishedResult { applied, alreadyApplied, noRow }

abstract interface class TripsRepository {
  // ... insertStarted, delete, byId, watchRecentDestinations (T22, không đổi)

  /// D2: in one transaction, UPDATE trips SET ended_at, result, end_reason, alarm_at, alarm_reason, dismissed_at,
  /// snooze_count, travelled_m, vehicle_guess = values of [f] WHERE id = f.tripId AND result IS NULL.
  /// 1 row → applied (+ the updated record); 0 rows → alreadyApplied if the id exists, else noRow (record null).
  /// Never touches started_at, the destination or the alarm choice.
  Future<({ApplyFinishedResult result, TripRecord? record})> applyFinished(FinishedTripMsg f);

  /// Newest first (started_at DESC), at most [limit] rows, simulated included.
  Stream<List<TripRecord>> watchHistory({int limit = kHistoryLimit});

  /// Real (simulated = false) trips with started_at >= [sinceMs] (month stats).
  Stream<List<TripRecord>> watchRealTripsSince(int sinceMs);

  /// D4: UPDATE trips SET ended_at = [endedAtMs] WHERE result IS NULL AND ended_at IS NULL
  /// AND started_at < [startedBeforeMs] AND (exceptTripId IS NULL OR id <> exceptTripId). Returns the row count.
  Future<int> markUnfinishedAsUnknown({required String? exceptTripId, required int startedBeforeMs, required int endedAtMs});
}
```
Với chuyến giả lập, các cột `ended_at`/`alarm_at`/`dismissed_at` lưu đúng giá trị của `FinishedTripMsg`, tức giờ ảo (T18 D14). Ghi doc
comment ở `tables.dart`: các cột này chỉ dùng tính thời lượng, không hiển thị như giờ đồng hồ khi `simulated`.

#### 3.2 `HistorySync` (`lib/features/history/data/history_sync.dart`)

```dart
final class HistorySync {
  new({required CoreBridge bridge, required TripsRepository repo, required Telemetry Function() telemetry,
       required int Function() nowMs});
  /// Serialized: a call while a run is in progress schedules exactly one more run after it.
  Future<void> sync();
}
final historySyncProvider = Provider<HistorySync>((ref) => HistorySync(
    bridge: ref.watch(coreBridgeProvider), repo: ref.watch(tripsRepositoryProvider),
    telemetry: () => ref.read(telemetryProvider), nowMs: () => ref.read(clockProvider).nowMs()));
```
(Dùng đúng tên hàm đồng hồ trong `lib/app/clock.dart`; nếu khác thì theo code.)

```
sync():
  finished = try bridge.pendingFinishedTrips() catch BridgeException → return     -- không có native: không làm gì
  acked = []
  for f in finished (thứ tự native, cũ trước):
    try:
      (r, rec) = repo.applyFinished(f)
      if r == applied: telemetry().analytics.log(tripEndEventOf(f, rec!))      -- T29: một lần mỗi tripId
      acked.add(f.tripId)                                                    -- applied / alreadyApplied / noRow đều ack
    catch e: reportNonFatal('historySync.apply', e, st)                      -- chỉ kiểu lỗi; KHÔNG ack → lần sau thử lại
  if acked.nonEmpty: try bridge.ackFinishedTrips(acked) catch BridgeException → bỏ qua (D2: giao lại thì vô hại)
  active = try bridge.currentTrip() catch BridgeException → return            -- không biết chuyến đang chạy → không đánh dấu
  n = nowMs()
  repo.markUnfinishedAsUnknown(exceptTripId: active?.config.tripId, startedBeforeMs: n − kOrphanGrace, endedAtMs: n)
  if active == null: telemetry().crash.setKey(CrashKey.tripActive, false)
```
- `tripEndEventOf(f, rec)` (thuần, `history_sync.dart`): `outcome`/`endReason`/`alarmReason` (`null` → `AlarmReasonTag.none`) ánh xạ
  1-1 theo tên; `snoozeCount`; `mode = alarmModeTagOf(rec.alarm.mode)`; `vehicleGuess = vehicleTagOf(f.vehicleGuess)`;
  `duration = durationBucket(f.endedAtMs − f.startedAtMs)` (cùng đồng hồ chuyến); `distance = distanceBucket(f.travelledM)`;
  `simulated = rec.simulated`. Không có tên hay toạ độ.
- `noRow` (dòng `trips` bị lỗi ghi ở T25, hoặc đã bị xoá): ack, không log `trip_end`, `AppLog` mức info "finished trip without row"
  (không kèm id).

**Kích hoạt** (`lib/app/app_background_tasks.dart`, `AppBackgroundTasks` là `ConsumerStatefulWidget`, đặt trong
`MaterialApp.router(builder:)`):
- `initState` → post-frame `sync()`.
- `AppLifecycleListener.onResume` → `sync()` và đăng ký `bridge.updates`; `onHide` → huỷ đăng ký. Chỉ nghe khi app hiển thị, để không
  giải mã mọi Step ở nền. Kết thúc chuyến xảy ra ở nền sẽ được lấy ở lần resume sau.
- Nhận `TripEndedMsg` → `sync()`. Bỏ qua mọi message khác.
- Lỗi stream → bỏ qua (giống `activeTripProvider`).

```dart
enum HistoryStatus { running, onTime, snoozed, missed, cancelled, unknown }

/// record.displayVehicle (T22: guess, else hint). Unknown vehicle → only in `all`.
List<TripRecord> filterHistory(List<TripRecord> records, HistoryFilter f);

/// result → onTime/snoozed/missed/cancelled. result null: endedAt == null && id == activeTripId → running;
/// endedAt == null && !activeKnown → null (no badge while screen 1's provider loads); otherwise unknown.
HistoryStatus? historyStatusOf(TripRecord r, {required String? activeTripId, required bool activeKnown});

final class HistoryStats {
  const new({required this.tripCount, required this.travelledM, required this.wokeOnTime, required this.alarmed});
  final int tripCount; final int travelledM; final int wokeOnTime; final int alarmed;   // alarmed = onTime + snoozed + missed
}
/// D6. [records] from watchRealTripsSince(monthStart); rows with result == null or simulated are ignored (defensive).
HistoryStats monthStats(List<TripRecord> records);

/// Local midnight of the 1st of [now]'s month, epoch ms.
int monthStartMs(DateTime now);

/// Restart is offered only for real, finished-or-unknown trips (not running, not simulated).
bool canRestart(TripRecord r, HistoryStatus? s) => !r.simulated && s != HistoryStatus.running;
```

### 7. Sửa `NapListRow` (`lib/core/design/widgets/nap_list_row.dart`)

- **N1**: `computeMaxIntrinsicWidth(h) = max(gaps + Σ child.getMaxIntrinsicWidth(h), 2 × trailingMax)`, với `trailingMax =
  trailing?.getMaxIntrinsicWidth(h) ?? 0`. Tương tự `computeMinIntrinsicWidth` dùng `getMinIntrinsicWidth`. Lý do: layout giới hạn trailing ở
  `W/2`. Khi `W = max(tổng, 2T)` thì trailing có đủ `T`, và tiêu đề có ≥ bề rộng của nó, vì `2T − T − (phần còn lại không kể tiêu đề) ≥
  tiêu đề` khi `2T ≥ tổng`. Không cộng thêm "phần còn lại" như gợi ý của tester: làm vậy thì hàng rộng thừa.
- **N2**: thêm `DebugOverflowIndicatorMixin` [F-DOI] cho `_RenderRowLayout`. Trong `performLayout` ghi `_overflow = max(0, used − maxWidth)`
  (`used` = gaps + leading + trailing + end, tính khi bề rộng hữu hạn). Trong `paint`, chỉ ở debug (`assert`), khi `_overflow > 0.0`
  thì `paintOverflowIndicator(context, offset, Offset.zero & size, containerRect mở rộng thêm _overflow theo hướng văn bản)`, giống
  `RenderFlex`. Release không đổi. Dry layout và intrinsic không đổi vì N2.
- Bỏ `skip: true` của "N1 max intrinsic width…" và "N2 overflowing row…" trong `test/core/design/widgets/nap_list_row_layout_test.dart`.
  Toàn bộ golden T20 và test các màn T21–T25 phải xanh. Nếu N2 làm lộ chỗ tràn thật ở một màn đã `done`, coder ghi vào Implementation
  notes kèm ảnh/ca test, không tắt N2.

**Pin.** `sync()` chỉ chạy khi mở app, resume hoặc kết thúc chuyến. Chỉ nghe stream khi app hiển thị. Không có hẹn giờ, không đánh thức nền.
Nghe thử tự dừng ≤ 10 s.

**Quyền riêng tư.** Không lưu thêm dữ liệu vị trí (D1). `trip_end` theo catalog T29, không có tên đích hay toạ độ. Log của `HistorySync`
và `AppSettingsController` chỉ có kiểu lỗi hoặc số lượng, không có `tripId`, tên hay toạ độ. `TripRecord.toString` giữ như T22. File ngôn
ngữ native chỉ chứa "vi"/"en". Chuỗi `SimDestination` là dữ liệu tổng hợp nhưng vẫn không log.

**a11y.** Mọi hàng/nút ≥ 44 px, không đặt chiều cao cố định cho vùng chứa chữ (T20 R9). Thẻ thống kê đọc thành một node ("5 chuyến tháng
11, 1.428 km đã đi, 4 trên 5 lần tỉnh đúng lúc": `historyStatsSemantics`). Mỗi `HistoryTripTile` gộp semantics: tên, dòng phụ, kết quả,
"Giả lập". Nút "Đặt lại" có nhãn riêng `historyRestart`. Chip lọc có `selected`. Hàng ngôn ngữ và âm là radio
(`checked` + `inMutuallyExclusiveGroup`). Công tắc có nhãn bằng tiêu đề. Slider đọc "{n} phần trăm" (`settingsVolumeSemantic`). Lối vào
giả lập không có action semantics: cử chỉ ẩn cho demo, người dùng TalkBack không cần (D13). Màn chạy ở cỡ chữ 2.0 trên 320 px không
tràn. Tương phản dùng token T20 (đã kiểm ≥ 4.5:1).

## Tiêu chí chấp nhận

1. **Lọc lịch sử** (TASKS): H11, H14, H15 xanh. Màn 11 hiện đủ 4 kết quả của PRD (Tỉnh đúng lúc / Báo lại / Lỡ trạm / Đã dừng) và
   "Đặt lại" 1 chạm mở màn 3 điền sẵn (H16).

3. **Dòng mồ côi** được đánh dấu và hiện "Không rõ kết quả", không đánh dấu nhầm chuyến đang chạy hay đang bắt đầu (H04, H05, H08, I03).

   mới mang giá trị mới (S05, S06, S07). Chuyến đang chạy không đổi (banner S16).
5. **i18n vi/en**: chọn ngôn ngữ đổi toàn app ngay, giữ qua lần mở sau, khung đầu đúng ngôn ngữ (S08, S10). Mọi khoá mới có ở cả hai ARB
   (TC12 T20). Thông báo native (kể cả `:ring`) theo ngôn ngữ đã chọn (K05, I02, M01).
6. **Giả lập**: nhấn giữ logo 3 giây mở sheet; chọn trace + 1×/10×/60× → màn 3 → chuyến chạy qua đường ống thật (SM04, SM05, I01). Chỉ hiện
   thời lượng tương đối, chuyến giả lập có nhãn trong lịch sử (D5).

8. **N1/N2**: 2 test repro bỏ `skip` và xanh, golden T20 không đổi (N01–N03).
9. Không tràn ở 320 px, cỡ chữ 2.0, vi/en, sáng/tối (H20, S18). Nút ≥ 44 px.
10. Không có toạ độ/tên đích trong log, Analytics, Crashlytics (H10, review đọc mã).
