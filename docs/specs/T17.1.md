## Bối cảnh & mục tiêu

- Màn 0 (T21) và thẻ "Sẵn sàng" (T22) đã có nhánh iOS ở Dart, nhưng native iOS vẫn là stub trả quyền cố định "đã cấp". Trên máy thật,
  người dùng không được hỏi quyền vị trí, nên `startTrip` của T17 sẽ luôn từ chối `permission-missing` (T17 §5.1). S3 lỗi #3: quyền Thông báo
  bị từ chối thì app im lặng, không dẫn vào Cài đặt.
- T23: màn 2 hiện "cách X km" từ vị trí hệ thống đã có; iOS đang trả `nil`.
- Quyền riêng tư: Android đã loại `napstop_db/` (toạ độ đích trong Lịch sử), `napstop_onboarding`, `napstop_permissions` khỏi sao lưu. iOS
  chưa làm: iCloud Backup chỉ tự loại `tmp` và `Library/Caches` [I-BAK-GUIDE], nên `Library/Application Support` (DB) và file
  `NSUserDefaults` (trong `Library`) được sao lưu.
- App Store yêu cầu privacy manifest khi dùng các "required reason API" [PRIV-REQ]; chuỗi xin quyền cần bản dịch theo ngôn ngữ máy.

### 2. Kiểu dữ liệu thuần (`Sources/TripRuntime/Permissions.swift`)

```swift
/// Raw platform readings, no Apple types (filled by NapStopIOS.PermissionProbe).
public enum LocationAuthRaw: Sendable, Equatable { case notDetermined, restricted, denied, whenInUse, always }
public enum AccuracyRaw: Sendable, Equatable { case full, reduced }
public enum NotificationAuthRaw: Sendable, Equatable { case notDetermined, denied, authorized, provisional, ephemeral }
public struct PermissionReadings: Sendable, Equatable {
    public let location: LocationAuthRaw
    public let accuracy: AccuracyRaw
    public let servicesEnabled: Bool
    public let notifications: NotificationAuthRaw
    public let alarmKit: AlarmKitAuth            // Ports.swift (T17): unavailable on iOS < 26
}

/// Mirrors PermissionStatusMsg (names = Pigeon case names).
public enum LocationAccessDTO: String, Sendable { case notDetermined, denied, whileInUse, always }
public enum PermissionStateDTO: String, Sendable { case notDetermined, denied, granted, notApplicable }
public struct PermissionStatusDTO: Sendable, Equatable {
    public let location: LocationAccessDTO; public let precise: PermissionStateDTO; public let locationServicesEnabled: Bool
    public let notifications: PermissionStateDTO; public let fullScreenIntent: PermissionStateDTO
    public let exactAlarm: PermissionStateDTO; public let batteryOptimizationIgnored: PermissionStateDTO
    public let alarmKit: PermissionStateDTO
}

public enum PermissionMapper {
    public static func status(_ r: PermissionReadings) -> PermissionStatusDTO
}

/// Port of Android LastKnownMath (T23). Pure.
public enum LastKnownMath {
    public static let maxNumbers = 100
    public static func validPairs(_ p: [Double]) -> Bool
    public static func roundForDisplay(_ meters: Double) -> Double
    /// Age from the fix timestamp (wall ms); fresh when 0 ≤ age ≤ maxAgeMs (a future timestamp counts as age 0).
    public static func isFresh(fixWallMs: Int64, nowWallMs: Int64, maxAgeMs: Int64) -> Bool
}
```

`PermissionMapper.status` (= T21 §9, không thêm quy tắc):

| Trường | Quy tắc |
|---|---|
| `location` | `notDetermined` → `notDetermined`; `restricted`, `denied` → `denied`; `whenInUse` → `whileInUse`; `always` → `always` |
| `precise` | `location ∈ {whenInUse, always}`: `full` → `granted`, `reduced` → `denied`; ngược lại → `notDetermined`. **Không bao giờ** `notApplicable` |
| `locationServicesEnabled` | `servicesEnabled` |
| `notifications` | `notDetermined` → `notDetermined`; `denied` → `denied`; `authorized`, `ephemeral` → `granted`; `provisional` → `denied` |
| `alarmKit` | `unavailable` → `notApplicable`; `notDetermined` → `notDetermined`; `denied` → `denied`; `authorized` → `granted` |
| `fullScreenIntent`, `exactAlarm`, `batteryOptimizationIgnored` | `notApplicable` |

`LastKnownMath` giống từng dòng bản Kotlin: `validPairs` — không rỗng, chẵn, ≤ 100 số, hữu hạn, lat ∈ [−90, 90], lng ∈ [−180, 180];
`roundForDisplay` — không hữu hạn hoặc ≤ 0 → 0; bước 10 m khi < 1 000 m, 100 m từ 1 000 m, `Math.round` (làm tròn nửa lên, như
`(x/step).rounded(.toNearestOrAwayFromZero)` cho số dương). Không dùng `NoticeFormatter.roundedDistanceM` của T17 (khác ở biên 995–999 m).

### 3. Phần Apple (`Sources/NapStopIOS/PermissionProbe.swift`, Runner `Bridge/IOSPermissionHostApi.swift`)

```swift
// NapStopIOS
public final class PermissionProbe: NSObject, CLLocationManagerDelegate, @unchecked Sendable {
    public func readings() async -> PermissionReadings                    // D2
    public func requestLocation(timeoutMs: Int64) async                    // D3; returns when determined or timed out
    public func requestNotifications() async                               // D4; errors swallowed (type name to os.Logger)
    public func requestAlarmKit() async                                    // D4; iOS < 26: no-op
    public func lastKnown() async -> (fix: RawFix?, authorized: Bool, servicesEnabled: Bool)   // CLLocationManager.location
    public func distancesM(from fix: RawFix, to pairs: [Double]) -> [Double]                  // CLLocation.distance(from:)
}
```

`IOSPermissionHostApi` (Runner, thay `PermissionHostApiStub`; `deviceInfo()`/`deviceStatus()`/`mapsConfig()` chuyển nguyên từ stub sang
`Bridge/DeviceBridge.swift` dạng `enum DeviceBridge` — đổi tên tham chiếu trong `RunnerTests.swift`, nội dung test không đổi):

```
status()                      = DTO→Msg(PermissionMapper.status(await probe.readings()))
request(kind):
  if inFlight → throw PigeonError("request-in-progress"); inFlight = true; defer inFlight = false     -- D5
  switch kind: .location → await probe.requestLocation(PERMISSION_PROMPT_TIMEOUT_MS)
               .notifications → await probe.requestNotifications()
               .alarmKit → await probe.requestAlarmKit()
  return status()
openSettings(target)          -- D6, sync trên main
distancesFromLastKnownM(pairs, maxAgeMs):
  guard LastKnownMath.validPairs(pairs), maxAgeMs > 0 else nil
  (fix, authorized, services) = await probe.lastKnown()
  guard authorized, services, let fix, LastKnownMath.isFresh(fix.timestampWallMs, nowWall, maxAgeMs) else nil
  return probe.distancesM(from: fix, to: pairs).map(LastKnownMath.roundForDisplay)
  -- lỗi bất kỳ → nil; KHÔNG log vị trí, khoảng cách, toạ độ ga (chỉ tên kiểu lỗi)
startBackgroundCheck/backgroundCheck/cancelBackgroundCheck: như stub
```
Mọi hàm bọc `guarded` (lỗi lạ → `internal` + tên kiểu, không gửi mô tả lỗi — T14 F3). `AppDelegate` đăng ký `IOSPermissionHostApi` thay stub.
`TripRuntime` (T17) không đổi: `IOSDeviceEnv` vẫn là nguồn cho `startTrip`; hai chỗ đọc cùng API nên cùng kết quả (test PU04).

### 6. Loại khỏi sao lưu

- `NapStopIOS/BackupExclusion.swift`: `static func excludeAppSupportSubdirectories(_ names: [String]) -> [String: Bool]` — với mỗi tên:
  `FileManager.url(for: .applicationSupportDirectory, in: .userDomainMask, appropriateFor: nil, create: true)` + tên, tạo thư mục nếu chưa có,
  `var v = URLResourceValues(); v.isExcludedFromBackup = true; try url.setResourceValues(v)`; trả kết quả (ok/lỗi) để journal ghi; lỗi không
  chặn khởi động.
- `AppDelegate.didFinishLaunching` gọi với `["napstop_db", "napstop_trip"]` **trước** `super.application(...)` (Flutter chưa chạy Dart).
  (`napstop_trip` T17 đã đặt khi tạo store; gọi lại vô hại.)
- Cờ màn 0 (D11): `app/lib/core/storage/file_key_value_store.dart` — `KeyValueStore` đọc/ghi một file JSON (ghi nguyên tử: file tạm rồi
  `rename`), tạo file trong `appDatabaseDirectory()`; `createOnboardingStore()` trên iOS dùng `FileKeyValueStore(<napstop_db>/onboarding.json)`,
  Android giữ `SharedPreferencesAsyncAndroidOptions`. Lỗi đọc → coi như chưa xong màn 0 (như hành vi hiện tại khi lỗi). Không di chuyển dữ liệu
  cũ (iOS chưa phát hành).
