  static const String destination = '/destination';
  static const String destinationPick = '/destination?mode=pick';
  static const String alarmSettings = '/alarm-settings';
  static const String tracking = '/tracking';
  static const String alarm = '/alarm';
  static const String overshoot = '/overshoot';

const String kDestinationModePick = 'pick';

extension AppNavigation on BuildContext {

### 5. Cơ sở dữ liệu drift (`lib/core/db/`)

#### 5.1 Mở kết nối

```dart
// lib/core/db/connection.dart
const String kDatabaseName = 'napstop';          // file napstop.sqlite
const String kDatabaseDirName = 'napstop_db';    // excluded from Android backup (D5)

/// <app support>/napstop_db, created if missing.
Future<Directory> appDatabaseDirectory() async {
  final support = await getApplicationSupportDirectory();
  final dir = Directory(p.join(support.path, kDatabaseDirName));
  await dir.create(recursive: true);
  return dir;
}

QueryExecutor openAppDatabase() => driftDatabase(
  name: kDatabaseName,
  native: const DriftNativeOptions(databaseDirectory: appDatabaseDirectory),
);
```
- `driftDatabase` mặc định dùng thư mục Documents [DF-PUB]; ở đây đổi sang Application Support như ví dụ trong tài liệu drift [DR-SETUP],
  thêm thư mục con để loại khỏi backup bằng một dòng. drift_flutter mở DB lười ở isolate nền, không chặn khởi động (PRD §5: cold start ≤ 2 s).
- iOS: Application Support **được** sao lưu iCloud. Đặt `isExcludedFromBackup` cho thư mục `napstop_db` là nghĩa vụ của **T17** (cùng chỗ với

#### 5.2 Bảng (schema v1)

Thời gian luôn là `INTEGER` epoch ms UTC (cùng đơn vị với Pigeon). Không dùng `DateTimeColumn`.

```dart
// lib/core/db/tables.dart
@DataClassName('TripRow')

level  = có blocking → blocked; có warning/caution → check; còn lại → ready   (guide không đổi mức)
action = có blocking hoặc chip quyền ở bước 3 → openPermissions
         ngược lại chỉ có batteryOptimization → openBatteryGuide
         ngược lại → none   (âm lượng, DND, pin chỉ để báo; app không đổi được cài đặt này, S2 R3)
showSleepModeHint = device.platform == android
```
`showSleepModeHint`: Chế độ/lịch sẽ tự bật trong đêm (ví dụ "Ngủ" 22:00) không đọc được nếu không có quyền truy cập policy (S2 V5-9), nên
trên Android thẻ luôn có một dòng nhắc chung (Q4).

Mức → giao diện: `ok`, `guide` → `NapTone.neutral`; `caution` → `NapTone.warning`; `warning`, `blocking` → `NapTone.danger` (T19: mức "Cảnh
báo" = cảnh báo đỏ; "Hướng dẫn" = không đỏ).

`readinessProvider`:
```
bridge ← ref.watch(coreBridgeProvider)
(permissions, status, info) ← Future.wait([bridge.permissionStatus(), bridge.deviceStatus() (lỗi → null), ref.watch(deviceInfoProvider.future)])
return evaluateReadiness(...)
```
Lỗi của `permissionStatus()` hoặc `deviceInfo()` → `AsyncError` → thẻ hiện trạng thái lỗi. `deviceStatus()` lỗi thì bỏ qua (thẻ chỉ còn chip
quyền). `HomeScreen` có `AppLifecycleListener(onResume: () => ref.invalidate(readinessProvider))`, và cũng invalidate khi quay về từ
`/onboarding`, `/battery-guide` (`await context.openOnboarding()` rồi invalidate). Không có tham số Remote Config.

### 12. Pin, quyền riêng tư, a11y

- **Pin:** màn 1 không hẹn giờ, không việc nền. `deviceStatus()` chỉ gọi lúc dựng màn và khi resume.

  `lib/core/trip`, `lib/features/home` (test S01). `toString()` của kiểu domain không chứa tên đích hay toạ độ (U12). Analytics chỉ theo
  §9.5 (không tên, không toạ độ). Không gửi tên route ra ngoài.
- **a11y:** vùng chạm ≥ 48 (ô đã lưu cao ≥ 88, hàng ≥ 64, nút T20); nhãn cho mọi control chỉ có icon (bottom nav có nhãn chữ); tương phản theo token

### Quyết định nhỏ đã tự đưa ra

1. **Thêm `meta: any`** vào `dependencies` (ngoài §13). Lint `avoid_equals_and_hash_code_on_mutable_classes` đòi
   `@immutable` cho các kiểu domain có `==`. Domain là Dart thuần nên không lấy `@immutable` từ Flutter. `meta` do Flutter
   SDK ghim (1.18.3), không tải gói mới. Cùng cách khai với `intl: any`.
2. `flutter pub add` trong Git Bash làm mất dấu `^` (do `flutter.bat` chạy qua cmd), nên pubspec được sửa tay đúng ràng
   buộc §13 rồi `flutter pub get`. Ghi lại để task sau khỏi gặp.
3. `build.yaml`: `generate_for: lib/core/db/**.dart` thay vì chỉ `app_database.dart`. Nếu chỉ khai `app_database.dart`,
   drift không phân tích `tables.dart` ("The referenced element, Trips, is not understood by drift").
4. build_runner 2.17 **bỏ qua** cờ `--delete-conflicting-outputs`, chỉ in cảnh báo "These options have been removed".
   README ghi lệnh không có cờ; bước CI có cờ hay không đều chạy được.
5. `activeTripStream` (thuật toán của `activeTripProvider`, tách ra để test) viết bằng `StreamController`, **không** dùng
   `async*`. Một hàm `async*` đang đợi trong `await for` chỉ thoát ở `yield` kế tiếp, nên `cancel()` treo mãi khi không
   có update (đã gặp: test timeout). Bản hiện tại subscribe `updates` **trước** khi đọc `currentTrip()`, rồi xử lý từng
   bước theo thứ tự trong một hàng đợi Future. Như vậy không mất update nào giữa hai bước. Lỗi của stream update bị
   nuốt (màn 1 không bị chặn), lỗi `currentTrip()` coi như không có chuyến.
6. R05: `appDatabaseDirectory({supportDirectory = getApplicationSupportDirectory})` nhận hàm thư mục support để test
   inject, thay cho `PathProviderPlatform` giả. Cách kia cần thêm dev dependency `path_provider_platform_interface`.
   Tear-off vẫn khớp `DriftNativeOptions(databaseDirectory: appDatabaseDirectory)`.
7. `TripDraft` giữ constructor `const` bằng private named parameter (`this._vehicleHint`). Getter `vehicleHint`
   trả `_vehicleHint ?? vehicleHintFor(destination.kind)`, còn `==` so theo giá trị đã suy ra.
8. Converter dùng lớp cơ sở `WireEnumConverter<T>`: `wireOf` là `switch` đầy đủ; `fromSql` tìm trong `values`, wire lạ
   thì ném `FormatException('Unknown wire value for <Type>')` (không chứa giá trị).
9. Thẻ "Sẵn sàng" dùng `AsyncValue.when` (mặc định `skipLoadingOnRefresh`). Khi resume hay bấm "Thử lại", thẻ giữ kết
   quả cũ tới khi có kết quả mới, không nháy "Đang kiểm tra…". "Thử lại" và resume cũng invalidate `deviceInfoProvider`
   **nếu nó đang lỗi**: provider này giữ suốt phiên và retry đã tắt, nên nếu không làm vậy thì lỗi `deviceInfo()` không
   bao giờ hết (test W12b).
10. Phòng thủ thêm ở §8.3 bước 5: `alarmMuted == true` sinh chip `alarmMuted(warning)` **kể cả khi** `alarmVolumePct`
    null. Spec chỉ xét khi có phần trăm. iOS trả cả hai trường null nên không đổi gì.
11. Màn 1 dùng `SingleChildScrollView` + `Column` (spec cho phép), không dùng ListView lười: mọi khối được dựng ngay
    (test, golden, TalkBack). Chuyến gần đây khi đang tải: không hiện gì, tránh nháy dòng "Chưa có chuyến nào".
