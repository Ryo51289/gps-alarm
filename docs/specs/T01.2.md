## Bối cảnh & mục tiêu

- Không có Mac, không có `gh` CLI. `ios-compile.yml` hiện chỉ chạy bằng `workflow_dispatch` (chỉ bấm được từ web) nên chưa chạy lần nào

- Orchestrator chỉ được push **nhánh CI**, không push `main` (PLAN Q4 = A). Repo là **private** (Q9): phút macOS tốn tiền thật, đắt gấp
  ~10 lần Linux [G-BILL].
- Mục tiêu: (1) chạy CI iOS bằng `git push` một nhánh `ci/ios-<loại>-<id>`, chỉ chạy job cần thiết; (2) đọc kết quả bằng `git fetch`;
  (3) có job Simulator cho XCTest + `flutter test integration_test`; (4) IPA thử có cờ chẩn đoán `NAPSTOP_DIAG`; (5) kiểm kiểu Swift cục bộ
  trên WSL bằng một script commit trong repo; (6) tiết kiệm phút.

### 4. Workflow `ios-compile.yml` (khung; coder viết đủ)

```yaml
name: iOS compile
on:
  workflow_dispatch:
    inputs:
      target: { type: choice, options: [both, simulator, device, swift, all], default: both }
      diag:   { type: boolean, default: false, description: 'Device ipa with NAPSTOP_DIAG (Diag.xcconfig)' }
  push:
    branches: ['ci/ios-**']
permissions: { contents: read }
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'push' }}
env: { FLUTTER_VERSION: '3.47.8', IOS_BUNDLE_ID: 'app.napstop' }

jobs:
  plan:            # ubuntu-24.04, timeout 5: checkout (sparse: .github/scripts) → ios-ci-plan.sh → outputs swift/sim/ipa/diag
  swift-macos:     # needs: plan; if swift; macos-latest; timeout 25 — như hiện tại + cache app/ios/Core/.build (§6.3)
                   #   + ghi result/summary.md (Xcode, Swift, dòng "Test run with", số test, thời lượng) và đuôi swift-test.log,
                   #     danh sách + sha256 các file trong $NAPSTOP_REPORT_DIR (để tester T13.x so với bản WSL)
  ios-sim:         # needs: plan; if sim; macos-latest; timeout 40 — §5
  ios-device:      # needs: plan; if ipa; macos-latest; timeout 35 — như hiện tại + Diag.xcconfig (D6) + cache gói SwiftPM
                   #   + bước "Build settings check": xcodebuild -showBuildSettings -workspace ios/Runner.xcworkspace -scheme Runner
                   #     -configuration Release | grep SWIFT_ACTIVE_COMPILATION_CONDITIONS → ghi vào summary; diag=true mà thiếu NAPSTOP_DIAG → lỗi
  publish-results: # needs: [plan, swift-macos, ios-sim, ios-device]; if: always() && needs.plan.result != 'skipped'
                   #   ubuntu-24.04, timeout 10, permissions: contents: write — §7
```
- Action ghim theo SHA như `ci.yml` (`actions/checkout`, `subosito/flutter-action`, `actions/upload-artifact`); thêm `actions/cache` và
  `actions/download-artifact` ghim SHA bản mới nhất (coder tra trang release, ghi phiên bản vào Implementation notes).
- Mỗi job macOS có bước cuối `if: always()` ghi `result/<job>/summary.md` (kết luận, thời điểm bắt đầu/kết thúc theo `date -u`, phiên bản
  Xcode/Flutter, các dòng tổng kết test) và tải lên artifact `result-<job>` (`retention-days: 3`). IPA vẫn là artifact
  `napstop-ios-unsigned` (7 ngày) như hiện tại.
- Giữ bước "Drop default-flavor for iOS" ở mọi job build Flutter (flutter/flutter#176820, hiện có).

### 5. Job `ios-sim`

```
1  checkout; Flutter (cache); cache gói SwiftPM của plugin (§6.3); flutter pub get --enforce-lockfile; drop default-flavor
2  flutter build ios --simulator --debug --no-codesign                       -- sinh Generated.xcconfig + bản build Simulator
3  UDID=$(app/ios/scripts/ci-sim.sh select); app/ios/scripts/ci-sim.sh prepare "$UDID" "$IOS_BUNDLE_ID"
4  XCTest:  timeout 900 xcodebuild test -workspace ios/Runner.xcworkspace -scheme Runner -destination "id=$UDID" \
              -resultBundlePath "$RUNNER_TEMP/xctest.xcresult" CODE_SIGNING_ALLOWED=NO 2>&1 | tee "$RUNNER_TEMP/xctest.log"
           summary: các dòng "Test Suite … passed/failed", "Executed N tests, with M failures"
5  Integration: đọc app/integration_test/ios_suite.txt; với mỗi dòng "<file> [lat,lng]":
           [lat,lng] có → ci-sim.sh location "$UDID" <lat,lng>
           timeout 900 flutter test <file> -d "$UDID" --dart-define=NAPSTOP_EXPECT_FLAVOR=dev 2>&1 | tee "$RUNNER_TEMP/it-<tên>.log"
           một file lỗi không dừng các file sau; job lỗi nếu có file lỗi
6  if: always(): ghi result/ios-sim/summary.md (Simulator đã chọn: tên + runtime; kết quả XCTest; từng file integration: pass/fail, thời lượng),
                 đuôi log; xcrun simctl shutdown all
```
`app/ios/scripts/ci-sim.sh` (bash, chỉ chạy trên macOS):
- `select`: `xcrun simctl list devices available -j` → iPhone có runtime iOS lớn nhất (ưu tiên ≥ 26) → in UDID; không có → lỗi rõ ràng.
- `prepare <udid> <bundle>`: `xcrun simctl boot` (đã boot thì bỏ qua), `xcrun simctl bootstatus <udid> -b`; in `xcrun simctl help location` và
  `xcrun simctl help privacy` (một lần, để ghi lại cờ có trên runner — PLAN §6.4); `xcrun simctl spawn <udid> defaults write <bundle>
  napstop.diag.fakeAlarms -bool YES` (cổng báo giả, T17 §5.13; trước T17 không ai đọc, vô hại); `xcrun simctl privacy <udid> grant location
  <bundle>` — lỗi thì **ghi cảnh báo, không dừng** (có thể cần app đã cài; khi đó chạy lại bước này sau khi `flutter test` cài app lần đầu,
  coder ghi cách nào chạy được vào Implementation notes).
- `location <udid> <lat,lng>`: `xcrun simctl location <udid> set <lat>,<lng>`.
- Không in toạ độ vào summary (log job có, vì là toạ độ fixture công khai trong `ios_suite.txt`; summary chỉ ghi tên file test).

`app/integration_test/ios_smoke_test.dart`: chỉ chạy khi `Platform.isIOS` (Android: `skip`). Ca: (1) app khởi động (`IntegrationTestWidgetsFlutterBinding`,
`app.main()`), (2) `PermissionHostApi().deviceInfo().platform == PlatformMsg.ios`, (3) `TripHostApi().currentTrip()` trả về không lỗi,
(4) `pendingFinishedTrips()` trả về list. Dùng lớp bridge có sẵn của app (như `bridge_smoke_test.dart`), không đụng hộp thoại quyền. Phải qua
`flutter analyze` (very_good_analysis).

**Lưu ý lần chạy đầu:** `RunnerTests` (có từ T14.1, chưa bao giờ chạy) và bản build Simulator (T14 B02, chưa chạy) có thể lỗi vì mã có sẵn.
Đó là phát hiện, không phải lỗi của T01.2: T01.2 đạt nếu workflow chạy đúng job và kết quả lên được `ci-results/…`; lỗi mã có sẵn → orchestrator
mở task sửa riêng (đề xuất `T14.2`).

### 6. Thời lượng, chi phí, cache

#### 6.1 Giá (repo private)

Theo trang billing hiện tại [G-BILL]: macOS 3/4 nhân **$0,062/phút**, Linux 2 nhân $0,006/phút (macOS ≈ 10,3 lần); gói Free có **$12/tháng**
dùng chung cho mọi phút (Pro/Team $18). Trang không nêu cách làm tròn theo job → ước lượng dưới giả định mỗi job làm tròn lên phút nguyên.
$12 ≈ **190 phút macOS/tháng** nếu không dùng Linux; `ci.yml` (Linux) cũng trừ vào khoản này. Khi hết khoản miễn phí mà ngân sách vượt mức là
$0 (mặc định), job sẽ không chạy.

#### 6.2 Ước lượng mỗi kiểu chạy

"Nóng" = cache trúng; "lạnh" = lần đầu / sau khi `pubspec.lock`, `Package.swift` hoặc phiên bản Xcode đổi. Header hiện tại của
`ios-compile.yml` ghi ~10–15 phút mỗi job; chưa có số đo thật → Implementation notes ghi số thật của 4 kiểu chạy đầu tiên, và
`summary.md` luôn ghi thời lượng từng job.

| Kiểu | Job | Phút macOS (nóng / lạnh) | Phút Linux | Chi phí ước lượng (nóng / lạnh) |
|---|---|---|---|---|
| `ci/ios-swift-*` | `plan` + `swift-macos` + `publish` | 6–9 / 12–15 | ~2 | $0,40–0,57 / $0,76–0,94 |
| `ci/ios-sim-*` | `plan` + `ios-sim` + `publish` | 18–25 / 30–38 | ~2 | $1,13–1,56 / $1,87–2,37 |
| `ci/ios-ipa-*` | `plan` + `ios-device` + `publish` | 12–16 / 20–25 | ~2 | $0,76–1,00 / $1,25–1,56 |
| `ci/ios-all-*` | tất cả (macOS chạy song song, tính tổng) | 36–50 / 62–78 | ~2 | $2,24–3,11 / $3,86–4,85 |

Hệ quả với $12/tháng: khoảng **4 lượt `all` nóng**, hoặc ~20 lượt `swift`. Quy tắc dùng (ghi vào `app/README.md`):
1. Kiểm cục bộ trước (§9); chỉ push khi L1/L2 của PLAN §6.1 đã xanh.
2. Dùng tiền tố hẹp nhất: đổi Swift thuần → `swift-`; đổi Runner/Info.plist/pbxproj → `sim-`; cần IPA cho máy → `ipa-`; `all-` chỉ trước khi báo
   `in-review`/trước Gate.
3. Không push lại cùng nhánh trong lúc đang chạy trừ khi muốn huỷ (D3).

### 7. `publish-results`

`.github/scripts/publish-ci-results.sh <results_dir> <ref_name>` (bash), môi trường: `REMOTE_URL` (mặc định
`https://x-access-token:${GITHUB_TOKEN}@github.com/${GITHUB_REPOSITORY}.git`; test đặt bằng đường dẫn bare repo cục bộ), `SECRET_VALUES`
(danh sách giá trị cần quét, tách dòng), `RUN_URL`, `SHA`, `NEEDS_JSON` (`${{ toJSON(needs) }}`).

```
1  gom results_dir/result-*/**  (từ download-artifact) → out/<job>/...
```

### Lệnh nghiệm thu cho orchestrator (Git Bash, sau khi commit T01.2 cục bộ)

Mỗi nhánh chạy trên commit `HEAD` cục bộ; push nhánh CI kéo theo các commit cục bộ chưa có trên `origin/main` (hiện 21 commit). Q4 = A

Với mỗi `<kind>` theo thứ tự `swift`, `sim`, `ipa`, `foo`:

```bash
cd /d/work/gps-alarm
git rev-parse HEAD                                   # ghi lại sha
git push origin HEAD:refs/heads/ci/ios-<kind>-t012
# Chờ gợi ý: swift 10-15 phút, sim 25-40, ipa 20-30, foo 2-3. Fetch lỗi "couldn't find remote ref" = chưa xong, chờ thêm.
# Quá 55 phút (timeout lớn nhất 40 + 15) mà chưa có → báo PO xem trang Actions.
git fetch origin ci-results/ci/ios-<kind>-t012
git show FETCH_HEAD:summary.md
git show FETCH_HEAD:meta.json                        # "sha" phải bằng sha ở trên (lượt bị huỷ cũng publish)
git ls-tree -r --name-only FETCH_HEAD
```
CI06: `git show FETCH_HEAD:summary.md | grep SWIFT_ACTIVE_COMPILATION_CONDITIONS` trên nhánh kết quả của `ipa`. IPA tải bằng trình
duyệt từ trang run (`RUN_URL` trong `summary.md`), artifact `napstop-ios-unsigned`.
