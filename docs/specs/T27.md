
**Luồng A — "Xem đường quay lại" trên màn native (chính).** `AlarmActivity` → `UserDismiss(routeBack=true)` (T16 D7: ghi `pendingDismiss`,
dừng âm, `RING_EVENT DISMISSED` → engine ENDED, FGS `location` dừng) → `requestDismissKeyguard` → `startActivity(MainActivity, napstop.launch=
overshootRoute, napstop.tripId, napstop.pastM)` → `LaunchActions.set` → (app nóng) Flutter `onResume` / (app nguội) frame đầu →
`consumeLaunchAction()` → `go('/overshoot?trip=<id>&past=<m>&open=1')` → màn 8 đọc `byId` → tự mở Maps một lần (D12).

**Luồng B — màn native không lên (dự phòng).** App `resumed`, `TripStateMsg` có chuông kêu (`ringingNow`, §4.1) ≥ 4 s → `showAlarmScreen(tripId)`
→ true: chờ thêm 4 s, nếu vẫn `resumed` và vẫn kêu → `push('/alarm?trip=…')`; false/lỗi → `push` ngay. Màn 5 Flutter: Báo lại → `snooze`;

Hết kêu (`ringingNow` false, `TripEndedMsg` của chuyến, hoặc chuyến khác) → `pop` (nếu `canPop`, không thì `go('/home')`).

**Luồng C — tắt bình thường trên màn native.** Flutter không làm gì (không có launch action). Màn bên dưới (T22/T26) nhận `TripEndedMsg`.

### 4. Kiểu và logic thuần (Dart, `lib/features/alarm/domain/`)

#### 4.1 `ring_ui_rules.dart`

```dart
/// Grace before Flutter acts on a ring while the app is visible (D1).
const Duration kRingUiGrace = Duration(seconds: 4);

/// The engine says this trip's alarm is sounding now.
bool ringingNow(TripStateMsg? s) =>
    s != null && s.alarmRinging && (s.phase == TripPhaseMsg.alarming || s.phase == TripPhaseMsg.overshot);

enum AlarmVariant { arriving, overshoot }

AlarmVariant alarmVariant(TripStateMsg s) =>
    s.phase == TripPhaseMsg.overshot || s.overshootPastM != null || s.alarmReason == AlarmReasonMsg.overshoot
        ? AlarmVariant.overshoot : AlarmVariant.arriving;      // = RingCopy.variant (T16)

/// T10 §2.3: phase ALARMING && snoozeCount < maxSnoozes; never on overshoot.
bool snoozeAllowed(TripStateMsg s, AlarmSettingsParams p) =>
    s.phase == TripPhaseMsg.alarming && s.snoozeCount < p.maxSnoozes && alarmVariant(s) == AlarmVariant.arriving;
```
`AlarmSettingsParams.fromOverrideJson(config.engineParamsJson)` (T25, đã có) cho `snoozeS`, `maxSnoozes` đúng như engine của chuyến.

#### 4.3 `ring_ui_policy.dart` — máy trạng thái thuần của coordinator (test bằng `fake_async`)

```dart
sealed class RingUiInput {}
final class LifecycleChanged extends RingUiInput { LifecycleChanged(this.resumed); final bool resumed; }
final class StateSeen extends RingUiInput { StateSeen(this.state); final TripStateMsg? state; }   // null = no trip / ended
final class GraceElapsed extends RingUiInput { GraceElapsed(this.tripId, this.generation); final String tripId; final int generation; }
final class NativeAnswered extends RingUiInput { NativeAnswered(this.tripId, this.generation, this.shown); final String tripId; final int generation; final bool shown; }
final class FallbackClosed extends RingUiInput {}   // /alarm popped

sealed class RingUiEffect {}
final class StartGrace extends RingUiEffect { StartGrace(this.tripId, this.generation); ... }   // timer kRingUiGrace → GraceElapsed
final class CancelGrace extends RingUiEffect {}
final class AskNative extends RingUiEffect { AskNative(this.tripId, this.generation); ... }     // showAlarmScreen → NativeAnswered
final class PushFallback extends RingUiEffect { PushFallback(this.tripId); ... }

enum RingUiStage { idle, grace, askingNative, waitingNative, fallbackShown }
final class RingUiState { final bool resumed; final String? ringingTripId; final RingUiStage stage; final int generation; ... }

(RingUiState, List<RingUiEffect>) reduceRingUi(RingUiState s, RingUiInput i);
```
Quy tắc:
```
mọi input: cur = (s.resumed && ringingTripId != null)
LifecycleChanged(false)            → stage idle (trừ fallbackShown giữ nguyên), generation++, [CancelGrace]
StateSeen(st): id = ringingNow(st) ? st.tripId : null
   id == null                      → ringingTripId null; stage fallbackShown giữ (màn 5 tự pop); còn lại idle, generation++, [CancelGrace]
   id != s.ringingTripId           → ringingTripId = id; nếu resumed && stage != fallbackShown: stage grace, generation++, [StartGrace(id, gen)]
   cùng id                         → không đổi
LifecycleChanged(true) khi đang kêu và stage idle → stage grace, generation++, [StartGrace]
GraceElapsed(id, g) đúng gen, resumed, đang kêu id:
   stage grace                     → stage askingNative, [AskNative(id, g)]
   stage waitingNative             → stage fallbackShown, [PushFallback(id)]      -- native trả true mà vẫn không phủ lên
NativeAnswered(id, g, shown) đúng gen: shown → stage waitingNative, [StartGrace(id, g)]; !shown → stage fallbackShown, [PushFallback(id)]
FallbackClosed                     → stage idle (nếu vẫn kêu và resumed: lại grace)
input sai generation / sai tripId  → bỏ qua
```
Bất biến: tối đa một `PushFallback` cho mỗi lần `stage` rời `idle`; không bao giờ `PushFallback` khi `resumed == false`.

#### 4.4 `route_back.dart`

```dart
/// Maps URLs directions to the destination (D8). null when lat/lng are not finite or out of range.
/// Fixed 6 decimals with '.', independent of the locale (Dart toStringAsFixed).
/// PRIVACY: the URI holds the destination coordinates — never log it, never put it in telemetry.
Uri? routeBackUri(double lat, double lng) =>
    (!lat.isFinite || !lng.isFinite || lat.abs() > 90 || lng.abs() > 180) ? null
        : Uri.https('www.google.com', '/maps/dir/', {'api': '1', 'destination': '${lat.toStringAsFixed(6)},${lng.toStringAsFixed(6)}'});
//  → https://www.google.com/maps/dir/?api=1&destination=17.468800%2C106.622300

/// Query of /overshoot (D9). toString prints no tripId value? (tripId is not sensitive; prints `OvershootArgs(past: set|unset, open)`).
final class OvershootArgs {
  const new({required this.tripId, this.pastM, this.autoOpen = false});
  final String tripId; final int? pastM; final bool autoOpen;
  /// trip ~ ^[A-Za-z0-9_-]{1,64}$ else null; past: int 0..1000000 else null; open == '1'.
  static OvershootArgs? fromUri(Uri uri);
  String toLocation();   // '/overshoot?trip=<id>[&past=<m>][&open=1]'
}

/// D12: auto-open only for a recent trip (cap 48 h, T10 §4.13).
bool mayAutoOpen(TripRecord? r, DateTime now) =>
    r != null && now.millisecondsSinceEpoch - r.startedAtMs <= const Duration(hours: 48).inMilliseconds;
```
