## Thiết kế

### 1. Thành phần & luồng dữ liệu

```
 màn 2 / màn 1 / màn 12 ── extra ──▶ AlarmSettingsScreen (ConsumerStatefulWidget, giữ AlarmSettingsViewState)
                                       │ initState: reader.current() MỘT lần → AlarmSettingsParams.fromOverrideJson
                                       │            prefs.load*()  ·  bridge.permissionStatus/deviceInfo/batteryStatus (gợi ý)
                                       │ build: hàm thuần (warning, preAlertHint, summary, format)
                                       ▼ bấm "Bắt đầu theo dõi"
                                     TripStarter.start(StartRequest)
                                       ├─ bridge.permissionStatus + deviceInfo → startBlockers → StartBlocked
                                       ├─ buildTripConfig + validateTripConfig → StartFailed(invalidDestination|generic)
                                       ├─ bridge.batteryStatus (chỉ cho analytics)
                                       ├─ bridge.startTrip(config, destLat, destLng, simulation) → lỗi → StartBlocked|StartFailed
                                       ├─ StartedTripWriter.insertStarted (lỗi: báo non-fatal, vẫn tiếp)
                                       └─ TripStartReporter.started → StartSucceeded(tripId)
                                     → context.go(AppRoutes.trackingFor(tripId))
```

- Trạng thái màn hình giữ trong `State` (không cần provider family). Phụ thuộc lấy qua provider để test thay bằng fake.
- `TripStarter` là lớp domain dùng lại được (T22 có thể dùng nếu "đặt lại 1 chạm" bắt đầu thẳng không qua màn 3).

**Máy trạng thái màn hình**

```
loading ──prefs đã đọc──▶ editing ──bấm Bắt đầu──▶ starting
                            ▲                         │ StartBlocked → editing + sheet thiếu quyền
                            │                         │ StartFailed  → editing + banner lỗi
                            └─────────────────────────┘ StartSucceeded → go(màn 4) (màn 3 bị thay khỏi stack)
```
- `loading`: chưa đọc xong prefs → hiện header + `CircularProgressIndicator` giữa màn (tránh nội dung nhảy giá trị). Thường < 50 ms.
- `starting`: `AbsorbPointer` phủ nội dung, nút Bắt đầu hiện nhãn "Đang bắt đầu…" và `onPressed: null`, `PopScope(canPop: false)`, nút
  quay lại không phản hồi (pop lúc này có thể để lại chuyến chạy mà người dùng không thấy).
- Banner lỗi bị xoá khi người dùng đổi bất kỳ cài đặt nào hoặc bấm Bắt đầu lại.

```dart
final class AlarmSettingsParams {
  const new({...});                            // 15 trường int như bảng
  static const AlarmSettingsParams defaults = ...;
  factory fromOverrideJson(String? json);      // thuật toán dưới
  int expectedSpeedKmh(VehicleKindMsg v);      // train/coach/bus/unknown
}

bool shortDistanceWarning(int thresholdM, VehicleKindMsg vehicle, AlarmSettingsParams p) =>
    thresholdM * 36 < p.shortDistanceWarnS * p.expectedSpeedKmh(vehicle) * 10;      // T10 §4.7, toàn int
/// Giây đi hết thresholdM ở tốc độ dự kiến, làm tròn xuống (chỉ để hiển thị).
int shortDistanceLeadS(int thresholdM, int speedKmh) => (thresholdM * 36) ~/ (speedKmh * 10);
```
Giá trị lớn nhất: 10000·36 = 360 000; 600·150·10 = 900 000 — không tràn.

**Thuật toán `fromOverrideJson`** (bit-compatible với `EngineParamsFactory.fromOverrides` T10 §5 trên các khoá này):
```
json == null hoặc rỗng → defaults
obj = try jsonDecode(json) catch → defaults;  obj không phải Map<String, dynamic> → defaults
với mỗi khoá K trong bảng: v = obj[K]
   parseI(v, min, max):
     v is int    → (min ≤ v ≤ max) ? v : null
     v is double → (v.isFinite && v == v.truncateToDouble() && min ≤ v ≤ max) ? v.toInt() : null   // so khoảng TRƯỚC toInt; -0.0 → 0
     khác (String, bool, null, Map, List) → null
   null → giữ mặc định của K
khoá lạ → bỏ qua
G4: nếu lowBatteryAlarmPct ≥ lowBatteryEarlierPct (sau bước trên) → cả hai về mặc định (5, 15)
```
- Không log giá trị (T29 §6). JSON trùng khoá: `jsonDecode` lấy giá trị sau cùng (ghi vào việc cho T12 để Kotlin cùng hành vi).
- Không nhóm G1–G3, G5–G7 nào chứa các khoá trên, nên chỉ G4 áp dụng.

```dart
sealed class PreAlertHint { const new(); }
final class PreAlertAtMinutes extends PreAlertHint { const new(this.minutes); final int minutes; }
final class PreAlertAtDistance extends PreAlertHint { const new(this.meters); final int meters; }
final class PreAlertSkipped extends PreAlertHint { const new(this.thresholdMin); final int thresholdMin; }

int minutesOf(int s) => (s + 30) ~/ 60;                                      // roundHalfUp
PreAlertHint preAlertHint(TripSettings s, AlarmSettingsParams p) => switch (s.mode) {   // khớp T10 §4.6
  AlarmModeMsg.distance => PreAlertAtDistance(max(p.preAlertDistanceFactor * s.distanceThresholdM, p.preAlertMinDistanceM)),
  AlarmModeMsg.time => p.preAlertLeadS - s.timeThresholdMin * 60 >= p.preAlertMinGapS
      ? PreAlertAtMinutes(minutesOf(p.preAlertLeadS)) : PreAlertSkipped(s.timeThresholdMin),
  AlarmModeMsg.smart => PreAlertAtMinutes(minutesOf(p.preAlertLeadS)),
};
```
