# Giao thức thử T20 — TC43–TC45: catalog design system trên Android thật/emulator

Dành cho: người chạy thử có emulator Android **API 35 hoặc 36** (bắt buộc cho phần sheet: Android 15+ ép tràn viền)
hoặc điện thoại Android 15+ cắm USB. Spec: `docs/specs/T20.md` (TC43, TC44, TC45, tiêu chí 1 và 4).
Review: `docs/reviews/T20.md` (mục "Ghi chú cho tester" vòng 1 và 2).

Trạng thái: **chờ thiết bị**. Máy dev hiện chỉ có system image API 34 (`napstop_api34`, `amomi_api34`); lần thử khởi động
`napstop_api34` ngày 01/11/2026 bị treo ở `offline` (màn hình đen), đã tắt. Không dùng `amomi_api34`.

Phần tự động hoá được đã có trong `app/test/core/design/catalog_app_test.dart` (mở từng section ở 3 chủ đề, cỡ chữ 2.0, vi/en;
sheet với thanh điều hướng 48 dp giả lập; trang Licenses có "Be Vietnam Pro") và `catalog_sweep_test.dart`. Giao thức này
chỉ kiểm phần test máy ảo không làm được: font thật, thanh hệ thống thật, TalkBack, offline.

## Thiết bị

| # | Máy / AVD | Android (API) | Điều hướng | dpi | Ghi chú |
|---|---|---|---|---|---|
| 1 | Emulator Pixel (Google APIs x86_64) | 15 (35) hoặc 16 (36) | 3 nút | 420 | bắt buộc |
| 2 | (cùng AVD) | | cử chỉ | | bắt buộc cho bước 4b |
| 3 | (tuỳ chọn) máy hẹp ≤ 360 dp | | | | ghi chú review vòng 2, mục 4 |

Tạo AVD (nếu chưa có), trong Git Bash:
```bash
export ANDROID_HOME=/d/work/android-sdk
$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager "system-images;android-35;google_apis;x86_64"
$ANDROID_HOME/cmdline-tools/latest/bin/avdmanager create avd -n napstop_api35 \
  -k "system-images;android-35;google_apis;x86_64" -d pixel_6
```
Bật điều hướng 3 nút: Settings → System → Gestures → System navigation → 3-button navigation
(hoặc `adb shell cmd overlay enable com.android.internal.systemui.navbar.threebutton`).

## TC43 — font, dấu, cỡ chữ, offline, sheet

| Bước | Thao tác | Kết quả mong đợi | Ảnh | Đạt? | Ghi chú |
|---|---|---|---|---|---|
| 1 | Trang chủ catalog, chủ đề `light`, cỡ chữ `1.0`. Mở **Typography** | Chữ là Be Vietnam Pro (chữ "a" hai tầng, "g" một tầng, khác Roboto); dấu chồng "Ẵ Ổ ỗ ặ" ở `displayLarge` không bị cắt, không đè dòng trên | `typography_light` | | |
| 2 | Đi qua 11 section × 3 chủ đề (`light`, `dark`, `alarm`) | Không tràn (không có sọc vàng-đen), màu đúng chủ đề, nút back hoạt động | `<section>_<theme>` (33 ảnh) | | |
| 3 | Settings → Display → Font size **lớn nhất** + Display size lớn nhất; catalog chọn `System`. Mở Buttons, Cards and lists, Switch/option, Bottom sheet | Chữ to theo hệ thống (co giãn phi tuyến Android 14+), không tràn, không exception trong log `flutter run` | `system_max_buttons`, `system_max_cards` | | |
| 4a | Điều hướng **3 nút**. Bottom sheet → "Mở sheet" (cỡ `1.0`, rồi `2.0`) | Nút "Áp dụng" và dòng "Có thể đổi trong Cài đặt" nằm **hẳn trên** thanh điều hướng (khoảng cách ≥ 0 dp), bấm "Áp dụng" đóng sheet; thanh điều hướng không nhận mất cú chạm ở mép dưới nút | `sheet_3button_x1`, `sheet_3button_x2` | | |
| 4b | Điều hướng **cử chỉ**, lặp bước 4a | Như 4a; đáy sheet có thêm ~24 dp trống (đúng thiết kế) | `sheet_gesture_x1` | | |
| 5 | Bật **chế độ máy bay**, force-stop app, mở lại catalog, lặp bước 1 | Font vẫn là Be Vietnam Pro (bundle, không tải mạng) | `offline_typography` | | |
| 6 | Kiểm ký tự "→" bất kỳ chỗ nào (nếu có) | Font không có glyph "→" (Implementation notes); catalog đã thay bằng "-". Ghi lại nếu thấy ô trống | | | |
| 7 | (tuỳ chọn) Máy ≤ 360 dp, cỡ chữ `2.0`, Cards and lists | Tiêu đề hàng có leading + giá trị dài + chevron vẫn đọc được (không bị ép còn 1–2 ký tự) | `narrow_cards_x2` | | |

## TC44 — TalkBack

Bật TalkBack (Settings → Accessibility → TalkBack). Vuốt phải để đi qua từng phần tử.

| Bước | Phần tử (section) | Mong đợi TalkBack đọc | Đạt? | Câu đọc thực tế |
|---|---|---|---|---|
| 1 | Segmented control (Segmented) | Nhãn mục + "đã chọn" cho mục đang chọn; mục khác không có "đã chọn" | | |
| 2 | Switch row (Switch, option, radio) | Gộp "tiêu đề, phụ đề, bật/tắt"; chạm đúp đổi trạng thái | | |
| 3 | Option card | Tiêu đề + mô tả + "đã đánh dấu"/"chưa đánh dấu" (nhóm loại trừ) | | |
| 4 | Chip (Chips and badges) | Nhãn + "đã chọn" khi chọn; badge không đọc là nút | | |
| 5 | Nút icon (Buttons, Cards) | Đọc tooltip (vd "Cài đặt"), không đọc "nút không có nhãn" | | |
| 6 | Nút quay lại ở đầu mỗi section | "Quay lại" (vi) / "Back" (en) | | |
| 7 | Hàng danh sách (Cards and lists) | Gộp theo thứ tự tiêu đề → phụ đề → giá trị; chevron và icon tile không được đọc | | |
| 8 | Ô tìm kiếm dạng nút (Slider, big value, search) | Đọc gợi ý + "nút"; chạm đúp có hành động | | |
| 9 | Banner có `announce` (Status and banners) | Được đọc khi xuất hiện (live region) | | |
