# Giao thức thử T28 — Lịch sử, Cài đặt chung, ngôn ngữ native, lối vào giả lập (emulator + máy thật)

Dành cho: orchestrator (chạy integration gộp trên emulator sau khi gộp nhánh) và người thử trên điện thoại thật.
Spec: `docs/specs/T28.md` (I01–I03, M01–M03, §6, §8). Review: `docs/reviews/T28.md` ("Ghi chú cho tester").
Kết quả ghi vào cột cuối của mỗi bảng, rồi chép tóm tắt sang `docs/test-reports/T28.md` (lần chạy sau).

> Quyền riêng tư: chỉ dùng chuyến giả lập hoặc ga/bến chọn từ danh sách. Không chụp màn hình có vị trí thật. Khi chép log
> `dumpsys` vào báo cáo, chỉ giữ dòng tiêu đề thông báo và tên kênh.

## A. Integration trên emulator (I01, I03)

Chuẩn bị:
1. Emulator Android API 34+ (Google APIs), ngôn ngữ máy Tiếng Việt. Ghi: tên AVD, API, bản image.
2. Không có tester khác đang dùng emulator (T26 dùng chung).
3. Cấp quyền trước:
   ```bash
   adb shell pm grant app.napstop.dev android.permission.ACCESS_FINE_LOCATION
   adb shell pm grant app.napstop.dev android.permission.ACCESS_COARSE_LOCATION
   adb shell pm grant app.napstop.dev android.permission.POST_NOTIFICATIONS
   ```
   (Nếu app chưa cài thì chạy lệnh ở bước 4 một lần cho cài, rồi cấp quyền và chạy lại.)
4. Trong `app/`: `flutter test integration_test/t28_history_settings_test.dart -d <emulator-id>`

| # | Ca | Kết quả mong đợi | Kết quả |
|---|---|---|---|
| A1 | I01: màn 12 → nhấn giữ logo 3 s → `bus_hn_brt01` 60× → màn 3 Khoảng cách 1 km → Bắt đầu; chờ `AlarmMsg(DISTANCE)`; `dismiss`; tab Trips | `AlarmMsg` đến trong ≤ 2 phút thật, trong cửa sổ của T18 SI02 (giờ ảo); sau `sync` `pendingFinishedTrips` rỗng; dòng "Nhà chờ BRT Yên Nghĩa" có "Woke up on time" + "Simulated", **không** có nút đặt lại; thẻ tháng không tính chuyến này | |

| A3 | Toàn bộ `flutter test integration_test` (các file T18–T28) sau khi gộp nhánh | Xanh, không flaky qua 2 lần chạy | |

Lưu ý: chạy `flutter test integration_test` ghi đè APK bằng bản test. Trước phần B/C phải `flutter build apk --debug` và cài lại.
