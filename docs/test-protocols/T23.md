Dành cho: người chạy thử có điện thoại Android cắm USB (và iPhone/CI macOS cho TM08). Spec: `docs/specs/T23.md` (§6–§11, TM01–TM08,

## Điều kiện trước

| # | Việc | Ai |
|---|---|---|
| P1–P3 | Billing + 3 API (Maps SDK Android/iOS, Places API (New)), key `napstop-android` hạn chế `app.napstop.dev` + SHA-1 debug của máy chạy thử, quota ngày | PO (spec "Việc của PO") |
| K1 | `app/android/secrets.properties` (không commit): `MAPS_API_KEY_DEV=<key>` | người chạy thử |
| K2 | SHA-1 debug của máy: `keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android` → đã thêm vào key | người chạy thử + PO |

Lệnh (Git Bash, trong `app/`):
```bash
export PATH="/d/src/flutter/bin:/d/work/android-sdk/platform-tools:$PATH"; export PUB_CACHE=/d/src/pub-cache
flutter build apk --debug && adb install -r build/app/outputs/flutter-apk/app-dev-debug.apk     # TM01–TM05, TM07
flutter build apk --release                                                                  # TM06 (bản release)
```
Lưu ý môi trường (rút từ lần chạy emulator 02/11/2026): `flutter test integration_test/...` **ghi đè** `app-dev-debug.apk` bằng bản
có entrypoint là test (mở ra đứng ở màn splash). Build lại `flutter build apk --debug` trước khi thử tay. Integration test TI02 dùng chuỗi
tiếng Việt → máy phải ở ngôn ngữ vi (hoặc đổi ngôn ngữ app). Máy phải thức + mở khoá (`svc power stayon true`) khi chạy integration test.
