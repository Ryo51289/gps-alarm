# Giao thức đo T16 — Báo thức Android (`AlarmRingService` ở `:ring`) trên emulator và máy thật

Dành cho: tester / T31. Spec: `docs/specs/T16.md` (mục "Giao thức trên máy", tiêu chí chấp nhận 2, 3, 5, 6, 10).
Kết quả ghi vào `docs/test-reports/T16.md` (đạt hay không đạt đều ghi số, đường dẫn bằng chứng).

> Quyền riêng tư: journal `:ring` chỉ có enum, thời gian, tên lớp ngoại lệ. Không chụp màn hình có bản đồ/vị trí thật.

## Chuẩn bị (mọi lượt)

1. Ghi cho **mọi lượt**: hãng, model, bản Android, bản vá bảo mật, mức âm lượng báo thức, chế độ chuông (Thường/Rung/Im lặng),
   Không làm phiền (tắt / ưu tiên / chỉ báo thức / im hoàn toàn), quyền FSI, quyền thông báo, quyền báo thức chính xác.
2. Bản **dev debug**: `cd app && flutter build apk --debug`, `adb install -r -g build/app/outputs/flutter-apk/app-dev-debug.apk`
   (`-g` cấp sẵn quyền runtime; không có `POST_NOTIFICATIONS` thì không có FSI). Sau `connectedDevDebugAndroidTest` (AGP gỡ app khi
   xong) phải cài lại.
3. Lệnh (Git Bash: `export MSYS_NO_PATHCONV=1`):
   ```bash
   P=app.napstop.dev
   R="-n $P/app.napstop.core.trip.host.DebugCommandReceiver -a app.napstop.action.DEBUG"
   adb shell am broadcast $R --es cmd ring_test --es tripId <id> [--es source engine|fallback --es reason <AlarmReason>
        --es dismiss swipe|shake|math --ef volume 0..1 --ez ramp true|false --es vibration off|light|medium|strong
        --ez flash true|false --ez headphones true|false --ez snooze true|false --es sound default|horn|bell|beep|system]
   adb shell am broadcast $R --es cmd ring_stop --es tripId <id>          # = stopRinging(TRIP_ENDED) + clearTrip
   adb shell am broadcast $R --es cmd ring_facts --es tripId <id>         # logcat tag NapStopDebug
   adb shell am broadcast $R --es cmd ring_overshoot --es tripId <id> --ei pastM 1200
   adb shell am broadcast $R --es cmd ring_max_override --ei seconds 30   # 0 = bỏ; áp cho phiên chuông / lần mở app sau
   adb shell am broadcast $R --es cmd prealert_test --ez byDistance true
   adb shell am broadcast $R --es cmd preview_test --es sound bell --ef volume 0.5 ; adb shell am broadcast $R --es cmd preview_stop
   adb exec-out run-as $P cat no_backup/napstop_ring/journal_ring.ndjson  # journal :ring
   adb exec-out run-as $P cat no_backup/napstop_trip/journal.ndjson       # journal runtime (T15)
   adb shell pidof $P ; adb shell pidof $P:ring                            # pid process chính / :ring
   adb shell run-as $P kill -9 <pid>                                       # giết process
   adb shell dumpsys activity services $P | grep -E "ServiceRecord|isForeground|types="
   adb shell dumpsys audio | grep "usage=USAGE_ALARM" | grep -v released   # player đang phát
   ```
4. Chuyến thật (replay, app phải **đang hiển thị** khi gửi lệnh):
   ```bash
   adb shell mkdir -p /sdcard/Android/data/$P/files/replay
   adb push fixtures/traces/<trace>.gpx fixtures/traces/<trace>.expect.json /sdcard/Android/data/$P/files/replay/
   adb shell am broadcast $R --es cmd replay --es file <trace>.gpx --es expect <trace>.expect.json --ef speedScale <k> --es mode distance --ei threshold <m>
   ```
   **Chú ý (đo 04/11/2026):** `speedScale` phải giữ `max(spd) × k < maxPlausibleSpeedMps` (55 m/s), nếu không engine bỏ mọi fix
   (IMPLAUSIBLE) và không bao giờ báo. `coach_dn_langco_neardest` (max 17 m/s): `k ≤ 3`; `coach_gb_phuly_overshoot` (26,3 m/s): `k ≤ 2`;
   `bus_hn_brt01` (9,9 m/s): `k ≤ 5`. Dùng `threshold 10000` để chuông tới sớm.
5. Đặt lại giữa các lượt (không có cách dừng chuyến bằng adb): `adb shell am force-stop $P`, xoá
   `no_backup/napstop_trip/{active_trip,fallback_ledger,ring_config}.properties` và `no_backup/napstop_ring/*.properties` bằng
   `run-as … rm -f`, mở lại app.
6. Bằng chứng: chép journal/ảnh vào `app/build/t16-emu/` (không commit), ghi tên file vào bảng.


## Ghi chú

  (`ring_test … failed (RingStartException)`), T15 giữ khe GUARD (≤ 30 s) — đo thời gian tới lúc khe GUARD kêu.
- R2-1 (đã biết): sau khi kiểm, `run-as $P ls no_backup/napstop_ring/` có thể còn `<trip>.properties` `ringing=false, endedBy=STOPPED`.
