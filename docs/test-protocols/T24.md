# Giao thức thử T24 — TC37: tốc độ nạp và tìm ga/bến trên máy Android thật

Dành cho: người chạy thử có điện thoại Android tầm trung cắm USB. Spec: `docs/specs/T24.md` (§7.5, TC37, tiêu chí 5).
Mục tiêu: `StationRepository.load()` ≤ **400 ms**; p95 thời gian một lần `search()` (50 truy vấn) ≤ **16 ms**; bản **profile**.

> Quyền riêng tư: phép đo không đọc vị trí, không ghi nội dung truy vấn ra log release. Chỉ ghi số mili giây.

## Điều kiện trước (hook cần coder/T23 thêm — hiện **chưa có**)

App chưa có màn 2 (T23) và chưa có dependency `integration_test`. Cần một trong hai:
- (a) Thêm `integration_test: {sdk: flutter}` vào `dev_dependencies`, file `app/test_driver/integration_test.dart`
  (`integrationDriver()`), và `app/integration_test/station_search_perf_test.dart`. Test này: đo `StationRepository().load()`
  (lần đầu, `Stopwatch`), rồi chạy 50 truy vấn cố định dưới đây, mỗi truy vấn đo riêng, tính p50/p95/max, ghi bằng
  `IntegrationTestWidgetsFlutterBinding.reportData = {...}`. Không `print` nội dung truy vấn.
- (b) Màn T23 có chế độ đo tạm (chỉ build dev), hiển thị ba số trên.

50 truy vấn (cố định, theo thứ tự, lặp lại danh sách 5 lần cho đủ 50):
`dong hoi`, `my dinh`, `giap bat`, `ga ha noi`, `hue`, `da nang`, `sai gon`, `nha trang`, `vinh`, `quy nhon`.
(Trộn bậc exact / prefix / gợi ý loại. Thêm biến thể khó nếu muốn: `nha trnag` (fuzzy), `x` (20 kết quả), `zzqx` (không khớp).)

## Các bước

1. Sạc ≥ 50 %, tắt chế độ tiết kiệm pin, khởi động lại máy, chờ 2 phút cho máy rảnh.
2. Trên máy tính (Git Bash):
   ```bash
   export PATH="/d/src/flutter/bin:/d/work/android-sdk/platform-tools:$PATH"; export PUB_CACHE=/d/src/pub-cache
   cd /d/work/gps-alarm/app && adb devices -l
   flutter drive --profile --driver=test_driver/integration_test.dart \
     --target=integration_test/station_search_perf_test.dart -d <serial>
   ```
   (Phương án (b): `flutter run --profile -d <serial>`, mở màn đo.)
3. Ghi lại số đo vào bảng. Chạy **3 lần** (lần 1 là cold start sau khi cài; lần 2–3 mở lại app).
4. Lần cuối: gỡ app (`adb uninstall app.napstop.dev` hoặc id flavor tương ứng), cài lại, đo thêm 1 lần cold.
