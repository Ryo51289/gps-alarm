# Giao thức kiểm thử T27: màn 5 Báo thức phía Flutter và màn 8 Quá trạm

Dành cho: tester / T30 / T31. Spec: `docs/specs/T27.md` (Test cases MT1–MT6, AI-T27-1/2, IT1/IT2, Tiêu chí 2, 4, 5, 7).
Review: `docs/reviews/T27.md` (vòng 1 "Ghi chú cho tester", vòng 2 "Ghi chú cho tester (bổ sung)"). Kết quả ghi vào
`docs/test-reports/T27.md`, mỗi bước ghi Đạt/Không đạt kèm bằng chứng (lệnh, logcat, ảnh chụp không có bản đồ vị trí thật).

> Quyền riêng tư: URL Google Maps chứa toạ độ **đích** (ga công cộng trong dữ liệu seed). Không chụp màn hình có vị trí thật của máy.
> Không dán URL/toạ độ vào báo cáo.

## Chuẩn bị (mọi lượt)

1. Ghi: thiết bị (emulator `napstop_api34` hay máy thật: hãng, model, bản Android), ngôn ngữ máy, có app Google Maps hay không
   (`adb shell pm list packages | grep -E "maps|chrome"`), khoá màn hình (không / vuốt / PIN).
2. Bản dev debug, Git Bash, trong `app/`:
   ```bash
   export MSYS_NO_PATHCONV=1
   P=app.napstop.dev
   R="-n $P/app.napstop.core.trip.host.DebugCommandReceiver -a app.napstop.action.DEBUG"
   flutter build apk --debug && adb install -r -g build/app/outputs/flutter-apk/app-dev-debug.apk
   adb shell svc power stayon true
   adb shell am broadcast $R --es cmd ring_max_override --ei seconds 0     # bỏ override thời gian chuông của T16
   ```
3. **Dòng `trips` cho màn 8** (D7). Hai cách:
   - Seed (nhanh, dùng cho MT3, MT4, MT5, repro R-replay): chạy một lần
     ```bash
     flutter build apk --debug -t integration_test/manual/t27_seed_trips_probe.dart
     adb install -r build/app/outputs/flutter-apk/app-dev-debug.apk
     adb shell am start -n $P/app.napstop.MainActivity; sleep 8
     adb logcat -d -s flutter | grep NAPSTOP_T27     # "t27-recent written=true ageH=0.0", "t27-old written=true ageH=49.0"
     flutter build apk --debug && adb install -r build/app/outputs/flutter-apk/app-dev-debug.apk   # cài lại app thật, giữ DB
     ```
     Lưu ý: `t27-recent` "mới" tính theo lúc seed; quá 48 h thì seed lại. Màn 0 có thể hiện lần đầu: bấm qua.
   - Chuyến thật/giả lập do màn 3 tạo (MT1, MT2).
4. Chuông giả lập cho một chuyến có dòng `trips` (không chạy engine; đường `AlarmController.ringNow` thật, như T16):
   ```bash
   adb shell am broadcast $R --es cmd ring_test --es tripId t27-recent --es dismiss swipe --ef volume 0.2
   sleep 3; adb shell am broadcast $R --es cmd ring_overshoot --es tripId t27-recent --ei pastM 900
   ```
   Màn native hiện "ĐÃ QUA ĐIỂM ĐẾN" + "Xem đường quay lại". Toạ độ nút: `adb shell uiautomator dump /sdcard/u.xml && adb shell cat
   /sdcard/u.xml`, tìm `text="Xem đường quay lại"` (hoặc "Route back") → `adb shell input tap <x> <y>`.
5. Lệnh kiểm:
   ```bash
   adb shell dumpsys activity activities | grep -E "topResumedActivity|ResumedActivity"   # ai đang ở trên
   adb shell dumpsys activity activities | grep -o "ActivityRecord{[0-9a-f]* u0 $P/app.napstop.MainActivity" | sort -u | wc -l  # số ActivityRecord của MainActivity
   adb shell dumpsys activity services $P | grep -c AlarmRingService                        # 0 = chuông đã dừng
   adb shell pidof $P; adb shell pidof $P:ring
   adb logcat -d | grep "START u0" | grep -c -E "com.google.android.apps.maps|com.android.chrome"   # Maps/trình duyệt mở mấy lần (logcat -c trước)
   ```

Ghi chú:
- **Bộ khởi động MT1** (đến khi màn 3 có lối vào giả lập): `integration_test/manual/t27_mt1_probe.dart` ghi dòng `trips`, gọi
  `startTrip` giả lập 60× rồi chạy app thật. `flutter build apk --debug -t integration_test/manual/t27_mt1_probe.dart`,
  `adb install -r -g …`, `adb shell am force-stop $P`, `adb shell am start -n $P/app.napstop.MainActivity`,
  `adb logcat -d -s flutter | grep NAPSTOP_T27` (id chuyến). Chờ quá trạm:
  `adb exec-out run-as $P cat no_backup/napstop_trip/journal.ndjson | grep Overshoot | tail -1`. Xong thì cài lại bản thường.
- **Giới hạn chuông 5 phút** (`AlarmConstants.ringMaxMs` = 300 000, PO Q1 của T16). Với `coach_gb_phuly_overshoot`, báo đầu kêu ở
  t ≈ 2 340 s, quá trạm ở 2 605–2 680 s (1×), tức 265–340 s sau báo đầu. Nếu không ai chạm báo đầu, quá trạm có thể rơi vào **cuối** lần
  kêu đầu. Lượt 1: quá trạm ở giây 283, chuông bị `SILENCED` 17 s sau khi đổi sang biến thể quá trạm và không kêu lại (báo cáo, Quan sát
  O1). Muốn đủ thời gian bấm nút: `adb shell am broadcast $R --es cmd ring_max_override --ei seconds 600`, rồi `am force-stop` trước khi
  khởi động chuyến; sau đó trả về `--ei seconds 0`.
- Chuông giả lập (chuẩn bị 4) không có trạng thái chuyến trong runtime. Nó dùng được cho đường "Xem đường quay lại" → màn 8 → Maps (MT2,
  MT3, MT5, R-replay), nhưng không thay được MT1 ở phần "thông báo thường trực đã mất". `ring_test` chỉ hiện màn native khi app đang hiển
  thị (T16 D3).
- Google Maps trên máy mới hiện màn đăng nhập hoặc xin quyền vị trí lần đầu: vẫn tính là "Maps đã mở".
- Máy thật (Xiaomi/Samsung khi có): chạy thêm AI-T27-2 / R1: khi `AlarmActivity` hiện lúc app mở, Flutter phải rời `resumed`
  trong 4 s, nếu không màn 5 Flutter chồng lên sau 8 s. Multi-window (R2): ghi Quan sát.

## Tự động (chạy kèm mỗi lượt có emulator)

```bash
cd app/android && ./gradlew :app:connectedDevDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=app.napstop.T27RouteBackTest      # AI-T27-1, AI-T27-1b, AI-T27-2
cd app && flutter test integration_test/t27_alarm_flow_test.dart -d emulator-5554     # IT1 (~6 phút), IT2 (~11 phút)
```
Trước IT: cài bản dev debug một lần bằng `adb install -r -g` (hoặc `pm grant $P` `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`,
`POST_NOTIFICATIONS`); `svc power stayon true`; màn hình bật, không khoá. `connectedDevDebugAndroidTest` gỡ app khi xong, nên mất dữ liệu
seed (chạy seed sau).
