## Phần A: test tự động trên thiết bị (V11 qua validator native, `deviceStatus()`)

`$T` chạy 2 test: (1) V11: 16 385 đơn vị UTF-16 (ASCII, 8 192 emoji + 1, chuỗi có `= : # ! \ \n \t`, tiếng Việt) → `invalidConfig`
`engineParamsJson: too long`, không có chuyến; 16 384 → nhận, `currentTrip()` trả nguyên văn; khi đang có chuyến thì V11 báo trước
`tripActive`; 8 192 emoji (16 384 đơn vị) → nhận. (2) `deviceStatus()`: in `T14_1_DEVICE_STATUS {...}`, mọi mục khác null (trừ
`priorityAllowsAlarms`), `interruptionFilter ≠ unknown`; các `--dart-define=T141_*` (xem đầu file test) là giá trị mong đợi.

## Phần B: `engineParamsJson` sau khi process chết thật (probe)

```bash
flutter build apk --debug -t integration_test/manual/engine_params_restore_probe.dart
adb install -r build/app/outputs/flutter-apk/app-dev-debug.apk && adb logcat -c
adb shell am start -n app.napstop.dev/app.napstop.MainActivity     # đợi ~8 s
adb shell input keyevent HOME && adb shell am force-stop app.napstop.dev
adb shell am start -n app.napstop.dev/app.napstop.MainActivity     # đợi ~8 s
adb logcat -d -s flutter | grep NAPSTOP_T141
```

| Bước | Mong đợi | Kết quả emulator API 34, 02/11/2026 |
|---|---|---|
| B1 lần chạy đầu | `started t141-… length=16384` | **Pass** (pid 5645) |

(`am kill` không giết app đang ở nền ngay trên emulator này. Dùng `force-stop`, hoặc vuốt bỏ app khỏi Recents.)

## Phần C: Không làm phiền "Chỉ ưu tiên" trên máy thật API 30+ (chưa chạy, cần máy)

Shell không đổi được ngoại lệ DND (`cmd notification` chỉ có `set_dnd`), nên phải chỉnh tay trong Cài đặt / Quick Settings.

| Bước | Thao tác | Mong đợi (`T14_1_DEVICE_STATUS`) | Kết quả | Ngày / người chạy |
|---|---|---|---|---|
| C1 | Cài đặt > Không làm phiền > Báo thức: **bật**; bật DND (chế độ Ưu tiên) từ Quick Settings; `$T --dart-define=T141_FILTER=priority --dart-define=T141_ALLOWS_ALARMS=true` | `priority`, `true` | | |
| C2 | Tắt ngoại lệ "Báo thức", DND vẫn bật; `$T … FILTER=priority ALLOWS_ALARMS=false` | `priority`, **`false`** | | |
| C3 | Đổi DND bằng lịch tự động (Schedules) thay vì bật tay, lặp C1/C2 | giống C1/C2 (đọc chính sách **consolidated**) | | |
| C4 | Tắt DND; `$T … FILTER=all ALLOWS_ALARMS=null` | `all`, `null` | | |

## Phần D: âm lượng báo thức trên máy thật (chưa chạy, cần máy)

Trên emulator, shell không đổi được `STREAM_ALARM` (`SecurityException … AUDIO_ALARM_VOLUME` cho uid 2000). Chỉnh bằng thanh trượt
"Âm lượng chuông báo" trong Cài đặt > Âm thanh.

| Bước | Thao tác | Mong đợi | Kết quả | Ngày / người chạy |
|---|---|---|---|---|
| D1 | Kéo về thấp nhất | `alarmVolumePct` = `round(100·min/max)` (thường 14 với max 7, hoặc 0 nếu máy cho 0), `alarmMuted` false | | |
| D2 | Kéo lên cao nhất | `alarmVolumePct` = 100 | | |
| D3 | Bật "Im lặng hoàn toàn" (DND none) | `alarmMuted` true, `alarmVolumePct` 0 (như A4) | | |
