# Giao thức thử T21 — Màn 0 Cấp quyền, Màn 9 Hướng dẫn pin, `PermissionHostApi` Android thật

Spec: `docs/specs/T21.md` (I01–I03, M01–M10). Kết quả ghi vào `docs/test-reports/T21.md`.
Phần A chạy được trên emulator (đã chạy trên `napstop_api34`, xem test report). Phần B cần emulator API 26/29/31 hoặc máy thật.

> Quyền riêng tư: không chụp màn hình có vị trí thật. Lệnh dưới đây không in toạ độ.

## Chuẩn bị chung

- Git Bash, trong `app/`: `export PATH="/d/src/flutter/bin:$PATH"; export PUB_CACHE=/d/src/pub-cache`.
- `ADB="<ANDROID_HOME>/platform-tools/adb -s <device-id>"`.
- Bản app: `flutter build apk --no-pub --debug` (dev). **Lưu ý:** `flutter test integration_test` cài bản test đè lên app và **gỡ app khi
  xong** (mặc định `--uninstall`). Sau khi chạy integration test, build lại APK thường trước khi thử tay.
- Ghi lại để trả về sau: `settings get secure enabled_accessibility_services`, `secure accessibility_enabled`,
  `global always_finish_activities`, `system accelerometer_rotation`, `system user_rotation`, `global zen_mode`, `cmd uimode night`,
  `bmgr enabled`, transport đang chọn (`bmgr list transports`, dòng có `*`).
- Muốn đọc cây giao diện Flutter bằng `uiautomator dump`, bật tạm dịch vụ a11y "Accessibility Menu":
  `settings put secure enabled_accessibility_services com.android.systemui.accessibility.accessibilitymenu/com.android.systemui.accessibility.accessibilitymenu.AccessibilityMenuService`
  và `settings put secure accessibility_enabled 1`.

## Phần A — integration (`integration_test/permissions_t21_test.dart`)

Test in dòng `T21> STEP <bước>` rồi đọc `status()` mỗi 500 ms cho tới khi thấy trạng thái mong đợi (tối đa 90 s/bước). Người chạy (hoặc
script) thấy dòng `STEP` thì chạy lệnh adb tương ứng. Mỗi lần đọc còn kiểm bất biến: `precise ≠ notApplicable`, `location ≠ always`,
`alarmKit = notApplicable`, các mục Android khác `≠ notApplicable`.

### I01 — trạng thái thật

```bash
$ADB uninstall app.napstop.dev          # trạng thái quyền sạch
flutter test integration_test/permissions_t21_test.dart -d <device-id> --plain-name I01
```

| Dòng test in ra | Lệnh adb của người chạy | Kết quả mong đợi (dòng `T21> OK …`) | Kết quả |
|---|---|---|---|
| `STEP fresh` | — | `location=notDetermined precise=notDetermined notifications=notDetermined` (API 33+; < 33: `denied`), `exact=granted` (API 33+: nhờ `USE_EXACT_ALARM`), `battery=denied` | |
| `STEP coarse` | `$ADB shell pm grant app.napstop.dev android.permission.ACCESS_COARSE_LOCATION` | `location=whileInUse precise=notDetermined` (API 31+; ≤ 30: `denied`, test sẽ báo) | |
| `STEP fine` | `… pm grant … ACCESS_FINE_LOCATION` | `precise=granted` | |
| `STEP servicesOff` | `$ADB shell cmd location set-location-enabled false` | `services=false` | |
| `STEP servicesOn` | `… set-location-enabled true` | `services=true` | |
| `STEP fsiDenied` | `$ADB shell appops set app.napstop.dev USE_FULL_SCREEN_INTENT deny` (chỉ API 34+) | `fsi=denied` | |
| `STEP fsiAllowed` | `… USE_FULL_SCREEN_INTENT allow` | `fsi=granted` | |
| `STEP exactAppopDenied` | `$ADB shell appops set app.napstop.dev SCHEDULE_EXACT_ALARM deny` | API 33+: `exact=granted` (không thu hồi được). API 31/32: dùng ở M04 | |
| `STEP batteryWhitelisted` | `$ADB shell dumpsys deviceidle whitelist +app.napstop.dev` | `battery=granted` | |
| `STEP batteryOptimized` | `… whitelist -app.napstop.dev` | `battery=denied` | |
| `STEP notificationsGranted` | `… pm grant … android.permission.POST_NOTIFICATIONS` (API 33+) | `notifications=granted` | |

Không `pm revoke` trong lúc test: thu hồi quyền runtime giết process. Test đọc `androidSdkInt` và tự bỏ bước không áp dụng: `fsi*`
dưới API 34, `notificationsGranted` dưới 33; dưới 31 bước `coarse` kỳ vọng `precise=denied`.

### I02 — mở đúng trang cài đặt

```bash
flutter test integration_test/permissions_t21_test.dart -d <device-id> --plain-name I02
```
Với mỗi dòng `T21> OPENED <target> true`: chờ 3 s, ghi `dumpsys activity activities | grep -m1 topResumedActivity`, chụp màn, rồi
`$ADB shell input keyevent KEYCODE_BACK` (test chờ app quay lại rồi mở mục kế).

| target | Trang mong đợi (API 34) | API 31 | API 26 | Kết quả |
|---|---|---|---|---|
| appDetails | App info của NapStop Dev (`SpaActivity`) | như 34 | `InstalledAppDetails` | |
| locationServices | `Settings$LocationSettingsActivity` | | | |
| notifications | `Settings$AppNotificationSettingsActivity` của app | | | |
| fullScreenIntent | "Full screen notifications" của app (`SpaActivity`) | **false** (không áp dụng; test kỳ vọng `false`) | **false** | |
| exactAlarm | "Alarms & reminders" của app | `true`, trang của app | **false** | |
| batteryOptimization | Danh sách tối ưu pin (`HighPowerApplicationsActivity`) | | | |

## Dọn dẹp

Trả lại các giá trị đã ghi ở "Chuẩn bị chung" (`settings delete …` cho giá trị `null`), `cmd notification set_dnd off`,
`cmd uimode night no`, `cmd location set-location-enabled true`, `bmgr transport <transport cũ>` + `bmgr enable false`,
`settings delete secure backup_local_transport_parameters`, `dumpsys deviceidle whitelist -app.napstop.dev`; cài lại APK dev debug và
`pm clear app.napstop.dev`; `adb unroot` nếu đã `adb root`; tắt emulator (`adb emu kill`).
